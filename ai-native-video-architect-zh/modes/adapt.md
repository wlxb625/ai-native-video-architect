# ADAPT Mode V4.4

把已成立的故事、剧本、视觉脚本或分镜转译为完整、可复制、可外部执行的AI图片与视频提示词包。

## 启动

先保护用户现有作品：人物关系、核心机制、关键选择、高潮主体、结尾、开放程度、视觉和声音要求。

直接从缺失部分开始。已有完整剧本时不重写故事。

## 默认交付目标

当用户要求全套制作或外部平台实测时，目标为`FULL_CREATION_PACKAGE`，而不是生产平台管理：

```text
剧本制作拆解
→ 视觉圣经
→ 规划资产Prompt
→ 导演意图、摄影、灯光与表演设计
→ 完整Shot表
→ Shot–CF绑定
→ 逐镜头图片Prompt
→ 逐镜头视频Prompt
→ 内部闭环检查
→ 最终制作提示词包
```

## 规划资产不阻塞

角色、场景、道具和状态图片尚未真实生成时，使用`PLANNED_REFERENCE`编号继续编写整片Prompt。

不得把“母参考未选定”当成停止全套内容创作的理由。实际母参考只影响后续实测修复。

## Shot完整性

每个Shot必须明确：

- 剧情作用；
- 可见画面；
- 开始状态；
- 一个主要动作或揭示；
- 精确结束状态；
- 导演意图、观众位置与揭示顺序；
- 摄影方向和表演可读性；
- 逐镜灯光、可读性目标与情绪功能；
- 人物目标、内外情绪、微表情、呼吸、身体语言和情绪曲线；
- 参考绑定；
- 帧来源模式；
- Control Frames；
- 图片Prompt或继承说明；
- 视频Prompt或POST_ONLY方案；
- 上下镜头传递；
- 风险与稳定备用。

## CF规则

CF固定为Control Frame，只能属于某个Shot。使用`CF-SHOTID-S/E/Bn`编号。

没有预制尾帧时仍建立`TEXT_CONTRACT_ONLY`结束帧合同。

## 参考绑定

每镜不得出现空白参考字段。

没有新参考时，写明：

- 继承哪个上一镜尾帧；
- 继续使用哪些角色、场景和道具资产；
- 尾帧失效时的备用首帧Prompt。

## Prompt编译

图片Prompt负责一个静态瞬间及其可见表演状态；视频Prompt负责动作、微表情、呼吸、身体语言、情绪强度和摄影灯光随时间发生的变化。

每个生成型Shot必须有独立可复制的完整视频Prompt。`POST_ONLY`镜头必须给完整后期方案，不得被遗漏。

## 内部检查

读取`evals/full-package-integrity-check.md`，确保Shot总数、制作卡数量、参考绑定数量、图像来源数量和视频Prompt或后期方案数量一致。

逐对检查人物位置、视线、左右手、道具、动作进度、呼吸、姿态、表演强度、屏幕方向、场景地标、主光、白平衡和曝光；同时读取`evals/directing-coherence-check.md`和`evals/performance-direction-score.md`。

## 输出

使用`templates/full-creation-package.md`。没有实际媒体时标记`PROMPT_PACKAGE_READY`。

## 可选后续

用户真实生成图片或视频后，才进入`controllers/production-execution.md`和真实镜头验收。

## ADAPT禁止

- 已有剧本却擅自重写核心；
- 在参考图未生成处停止；
- Shot没有可见描述、导演意图、摄影或逐镜灯光；
- 人物Shot没有可见表演和情绪曲线；
- Shot参考字段为空；
- CF与Shot没有绑定；
- 生成型Shot没有图片来源或视频Prompt；
- 使用“同上”“略”“沿用前面”代替可执行说明；
- 编号在Shot表、CF、图片和视频Prompt间不一致；
- 没有真实媒体却声称已经验收通过。
