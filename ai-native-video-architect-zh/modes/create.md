# CREATE Mode V4.2

从原始灵感建立故事、剧本或视觉脚本，并在剧本确认后继续完成AI生图、分镜帧、导演级视频Prompt和后期方案。

## 启动

先判断用户已经提供想法、方向、故事、剧本、参考图、镜头表、分镜帧或视频片段。只补齐当前真正缺失的内容，不强制从头开始。

确定：

1. 操作模式：`CREATE`；
2. 主导演模式；
3. 创作路径：`COMMERCIAL` / `LITERARY` / `EXPERIMENTAL` / `HYBRID`；
4. 本轮具体交付物。

## 创意与故事

方向不足时确认类型、情绪、形式、主角、关系、场景范围、时长、画幅、声音和禁忌。已给信息不得重复询问。

需要探索时提供2至3个真正不同的方向，差异来自人物任务、核心事件或规则、递进、关键选择、结尾和制作难度，而不是只换美术风格。

故事方案至少包含：主角或主体、任务、核心事件或规则、递进、关键选择、高潮、情绪弧和最后图像。

## 剧本或视觉脚本

整片Prompt生产前必须有可制作文本。

剧情剧本至少包含场次、时间地点、人物状态、可观察动作、对白或无对白设计、道具环境变化、场景退出状态和下一场连接。

视觉脚本至少包含主体、初始状态、可见动作、环境变化、道具变化、情绪变化、最终状态和下一段连接。

无对白不等于没有剧本。

## 剧本确认后的继续制作

剧本由CREATE完成并确认后，不结束任务，也不要求切换Skill。按需读取剧本后Prompt工程模块，继续完成：

- 剧本制作拆解；
- 视觉设定；
- 最小核心参考图Prompt；
- 完整镜头表；
- 分镜帧Prompt；
- 导演级图生视频Prompt；
- 连续性、修复和后期方案。

## 最小参考原则

普通短片默认只做：

- 每名主要角色一张三视图或综合角色板；
- 每个主要场景一张无人物空镜；
- 必须稳定的核心道具结构或状态板；
- 剧情必须控制的特殊状态板。

不默认拆分面部、发型、服装、鞋履、手部、动作和多机位空镜。实际失败后才补。

## 分镜设计

先设计镜头，再写Prompt。每镜明确：镜头目的、主要动作、景别、焦段、机位、轴线、前中后景、构图、焦点、逐镜灯光、输入状态、精确输出状态、时长、声音、剪辑连接和风险。

每镜只承担一个主要重点。无动机运镜使用固定镜头。

## 分镜帧

图片Prompt负责准确静态瞬间。每镜必须设计首帧和结束帧合同。

尾帧不是按“镜头复杂不复杂”粗略决定，而是按连续性决定：下一镜需要继承姿势、视线、手部、道具、焦点或构图，或当前动作终点承担信息时，预生成尾帧。

## 视频生成模式

写视频Prompt前选择：

- 单首帧：仅低幅度运动且下一镜不依赖准确尾态；
- 首尾帧：动作终点、状态变化、道具位置、运镜终点或下一镜继承需要控制；
- 抽尾帧续拍：长动作分段连续；
- 遮挡硬切：遮挡前后切换稳定状态；
- 两段生成：构图变化大或多变化同时发生；
- 分层合成：镜面、倒影、雾气、文字和复杂状态。

禁止“所有镜头强制首尾帧”，也禁止“普通动作默认无控制单首帧”。

## 导演级视频Prompt

每镜必须包含：

- 输入模式和控制帧；
- 前中后景与构图；
- 起始姿态、视线、左右手、重心和道具接触；
- 分秒动作时间轴；
- 动作距离、方向、速度、重量和接触；
- 焦段、机位高度、距离、角度、轴线和屏幕方向；
- 运镜开始时间、结束时间、幅度和终点；
- 焦点、景深、曝光、白平衡、高光和暗部；
- 当前镜头真实主光、方向、色温、软硬、光比、亮区和阴影；
- 材质、环境动态和稳定项；
- 可验证结束帧和下一镜继承；
- 声音与负面约束。

只写“电影感、真实光照、缓慢推进”判定FAIL。

## 代表性测试

普通项目默认测试一个普通镜头；确实存在复杂变形、镜面、多人交互、特殊动作或复杂运镜时，再测试一个高风险镜头。

测试重点不只是人物是否动起来，还包括：能否抵达尾帧、主光是否稳定、焦点是否准确、手部道具是否连续、画面是否具有导演要求的层次。

## 用户资料

用户提供Prompt教程、模板或资料包时，先读取原文并使用原模板结构。自行补充必须明确区分。

## CREATE禁止

- 用户已有成熟内容却强制从创意访谈开始；
- 剧本完成后停止；
- 只有概念就批量写整片视频Prompt；
- 普通短片默认建立完整影视资产库；
- 所有镜头强制首尾帧；
- 下一镜依赖准确尾态却只提供无控制单首帧；
- 视频Prompt只写动作，没有画面、焦点、灯光和尾帧；
- 用户提供资料却凭经验改写并声称来自原资料；
- 强制所有作品获胜、反转或封闭结尾；
- 把用户变成逐资产、逐镜头确认操作员。
