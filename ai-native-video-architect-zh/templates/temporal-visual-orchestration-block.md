# Temporal Visual Orchestration Block V4.5

本模板只记录跨系统协调关系，不重复摄影、灯光、表演、环境和连续性模块中的具体参数。

## 启用判断

```text
【是否需要时空编排】
- REQUIRED / SIMPLIFIED / NOT_REQUIRED
- 判断依据：
```

- `REQUIRED`：两个以上系统存在明确先后、响应、对抗、同步或跨镜接力；
- `SIMPLIFIED`：普通叙事镜头，只需记录核心关系；
- `NOT_REQUIRED`：静态资产、结构图、纯后期或无时间变化任务，写明理由即可。

```text

```

## 模块委派

- 具体景别、焦段、机位、运镜：填写在`摄影方向`；
- 具体光源、光比、阴影和曝光：填写在`逐镜灯光方向`；
- 视线、呼吸、手部、重心和情绪节拍：填写在`人物表演方向`；
- 人物知识、道具归属、伤损、空间和跨镜状态：引用连续性台账；
- 场景结构、材质和背景大形：引用项目视觉策略与环境设计。

## 使用规则

1. 不把参考案例的具体顺序设为默认；
2. 枚举只用于内部判断，最终Prompt转译为当前镜头的自然语言；
3. `项目专属`必须写清可观察规则；
4. 连续与有意断裂都需要导演理由；
5. 简单镜头不得为了填表被过度设计；
6. 本块只统筹关系，不替代原有专业模块；
7. 连续性台账是剧情状态的唯一事实源，本块只选择接力通道。
