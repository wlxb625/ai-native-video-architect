# Asset Prompt Block Template

默认使用轻量资产块。目标是让创作者直接复制生成，不把每项简单资产写成完整影视制片合同。

```text
【资产名称】

【文件名称】

【用途】
说明该图在后续分镜中负责锁定什么。

【参考图】
- 无；或
- 参考图名称及用途。

【提示词】
写入完整可直接复制的主体提示词。优先沿用用户资料包中的角色板、人物三视图、人物细节与道具综合板、场景空镜或道具三视图模板，并填入当前项目的人物、场景、色调和禁止内容。

【负面约束】
只列当前资产最容易出现的错误，不堆叠无关负面词。

【输出要求】
- 画面比例：
- 单图或综合板：
- 背景：
- 不可裁切内容：
- 是否允许文字：
```

## 按需扩展字段

只有出现实际失败、用户要求专业生产包或项目进入STUDIO模式时，才增加：

```text
【必须保持】
【允许变化】
【稳定生成方案】
【局部修改Prompt】
【不合格情况】
【版本与后续依赖】
```

## 批量规则

S07一次性交付全部`REQUIRED`核心资产Prompt，而不是Asset Registry中所有可能资产。

默认数量遵循：

- 每个主要角色一张三视图或综合角色板；
- 每个主要场景一张无人物空镜；
- 核心道具与特殊状态按需生成；
- 发型、服装、手部、动作和多机位参考只在失败后增加。

用户在外部工具中自行生成和筛选，不需要逐项返回。用户回复“下一步”时进入分镜阶段。
