# Asset Prompt Block Template

每个资产使用一个完整可复制块。不得把正向Prompt、负面Prompt和输出规则分散到不同位置。

```text
【资产ID】

【资产名称】

【资产类别】
面部身份 / 三视图 / 发型 / 服装 / 交互 / 姿态 / 场景布局 / 空镜 / 多机位 / 道具 / 状态链 / 修复

【资产用途】
说明它锁定什么、服务哪些镜头，以及它不负责什么。

【来源场次】

【前置参考图】
- 参考图名称或资产ID：
- 参考职责：身份 / 服装 / 场景 / 道具 / 姿态 / 色调
- 首次生成无参考时明确写“无”。

【必须保持一致】
- 可验证锚点1
- 可验证锚点2

【允许变化】
- 允许模型自然变化的内容

【画面内容与布局】
说明视图、排版、主体位置、背景和完整性。

【正向Prompt】
写入完整可直接复制的详细Prompt。必须已经包含当前项目相关的视觉圣经、主体、场景、构图、光线、材质和一致性要求，不要求用户另行拼接全局前缀。

【负面Prompt】
按该资产高风险错误编写，至少覆盖身份、结构、人体、服装道具、场景、色调和输出错误中的相关项。

【输出规则】
- 比例：
- 横竖方向：
- 单图或多格：
- 视图数量：
- 背景：
- 是否允许文字：
- 不可裁切区域：
- 优先级：身份 / 结构 / 构图 / 氛围

【稳定生成方案】
说明一次生成方案和失败时分步方案。

【修改与修复Prompt】
保持其他区域不变，只修当前资产最常见的问题。

【不合格情况】
列出需要用户重新生成或局部修复的可见问题。

【文件命名】
ASSET_ID_V01.png

【后续依赖】
```

## 批量规则

S07一次性输出Asset Registry中全部资产块。用户在外部软件中生成和自审，不需要逐项返回。用户回复“下一步”时进入S09。
