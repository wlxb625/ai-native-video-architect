# Asset Prompt Block Template

默认使用轻量资产块。目标是让用户复制一次即可生成，不要求用户把摄影、灯光和材质字段自行拼接进Prompt。

```text
【资产名称】

【文件名称】

【用途】
说明该图在后续分镜中负责锁定什么。

【参考图及职责】
- 无；或
- 参考图名称：负责身份 / 服装 / 场景 / 道具 / 色调。

【资产形式判断】
单张身份主参考 / 全身服装参考 / 标准人物三视图 / 综合角色板 / 场景空镜 / 道具结构图 / 特殊状态图
- 选择原因：
- 为什么不增加其他资产：

【内部导演检查】
这一部分供Skill检查，可在用户只要求可复制Prompt时不展示。
- 构图与主体位置：
- 摄影机、焦段与角度：
- 景深、焦点、曝光和白平衡：
- 主光来源、方向、色温、软硬、亮区与阴影：
- 色彩与材质：
- 必须保持的一致性锚点：

【完整正向Prompt｜直接复制】
写成一条完整、自然、可直接输入生图模型的Prompt。

必须把当前资产需要的以下内容全部融合进正文：
- 主体身份与资产功能；
- 单图或拼板布局；
- 摄影机、焦段、机位、角度、焦点和景深；
- 曝光、白平衡、高光和暗部；
- 主光真实来源、方向、色温、软硬、受光区域和阴影；
- 色彩、皮肤、布料、木材、金属、纸张等材质；
- 背景和一致性要求。

不能只写人物或场景描述，再把摄影、灯光和材质留在外部字段。

【负面Prompt】
只列当前资产最容易发生的身份、构图、材质、灯光、裁切和文字错误，不堆叠无关负面词。

【输出要求】
- 画面比例：
- 分辨率或质量：
- 单图或拼板：
- 背景：
- 不可裁切内容：
- 是否允许文字：
- 后续引用方式：
```

## 角色参考默认规则

- 默认先生成一张独立的角色身份主参考，不默认密集六宫格；
- 全身、手部、三视图或综合角色板只有镜头需要、模型适合或用户明确要求时增加；
- 不得机械把每个角色固定拆成三张；
- 使用多视图板时，完整正向Prompt必须强调同一人物、同一骨相、同一服装和同一比例。

## 按需扩展字段

只有出现实际失败、用户要求专业生产包或进入STUDIO模式时，才增加：

```text
【必须保持】
【允许变化】
【稳定生成方案】
【局部修改Prompt】
【不合格情况】
【版本与后续依赖】
```

## 批量规则

S07一次性交付全部REQUIRED核心资产Prompt，但不输出所有可能资产。

默认遵循：

- 每名主要角色先判断一张身份主参考是否足够；
- 每个主要场景一张无人物空镜；
- 核心道具与特殊状态按需生成；
- 全身、手部、多视图和多机位只按镜头需要或失败升级；
- 用户在外部工具中自行生成和筛选，不需要逐项返回；
- 用户回复“下一步”时进入分镜阶段。
