# Video Shot Prompt Block Template

每镜的所有可复制内容写在同一块中。

```text

【使用模式】
单首帧图生视频 / 首尾帧视频 / 抽尾帧续拍 / 两段硬切 / 环境氛围 / 分层合成

【输入图】
唯一首帧：
尾帧（如有）：
参考资产：

【时长】

【起始状态】

【唯一主要动作】

【动作节拍】
- 起势：
- 过程：
- 收住：

【动作物理】
方向、速度、幅度、重心、脚部、手部和道具接触。

【摄影机】
- 起点：
- 景别和角度：
- 运动方式：
- 方向：
- 速度和距离：
- 终点：
- 运动动机：

【允许运动的环境元素】

【结束状态】

【声音】
环境、人物、道具、台词、音乐和沉默；工具不支持声音时转入后期。

【视频正向Prompt】
使用参考图作为唯一首帧……

【视频负面Prompt】
人物变脸、手部畸形、服装变化、道具消失、背景变形、色调跳变、镜头乱飞、动作滑行、无法抵达尾帧等针对性约束。

【输出规则】
- 时长：
- 帧率或项目参考：
- 画幅：
- 结尾稳定时间：
- 是否允许切镜：

【衔接方法】
抽尾帧 / 硬切 / 动作匹配 / 视线匹配 / 声音桥 / 直接切黑。

【失败修复】
局部帧修复、替换首帧、缩短动作、拆镜、固定机位、降低运镜复杂度或分层。

【版本命名】
```
