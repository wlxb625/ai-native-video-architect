# Storyboard Frame Prompt Block Template

```text
【镜头ID】

【镜头时间与时长】

【镜头唯一任务】

【参考图及职责】
- 角色身份：
- 服装状态：
- 场景空间：
- 核心道具：
- 姿态或交互：
- 色彩与光线：
- 上一镜稳定尾帧：

【上一镜输出状态】
- 人物位置、朝向和视线：
- 左右手与动作完成百分比：
- 道具位置、朝向和状态：
- 场景地标和屏幕方向：
- 主光、阴影、白平衡和曝光：

【下一镜输入要求】
说明下一镜必须准确继承什么。

【生成模式建议】
单首帧 / 首尾帧 / 抽尾帧续拍 / 两段硬切 / 分层合成
- 选择原因：

【画面空间与构图】
- 画幅：
- 前景：
- 中景：
- 背景：
- 主体位置：
- 构图重心和留白：
- 轴线与屏幕方向：
- 焦段、机位高度和角度：

【首帧设计】
- 人物姿势和重心：
- 头部朝向与视线：
- 左手：
- 右手：
- 道具接触：
- 动作空间：
- 一个准确的静态起点：

【首帧光学合同】
- 景深：
- 焦点：
- 曝光：
- 白平衡：
- 高光保护：
- 暗部细节：

【首帧逐镜灯光合同】
- 主光真实来源：
- 主光世界位置：
- 相对摄影机方向：
- 相对人物方向与高度：
- 软硬程度：
- 色温：
- 照亮区域：
- 阴影区域和方向：
- 辅光、实景灯和背景光：
- 光比：
- 与上一镜连续性：
- 禁止变化：

【首帧正向Prompt】
完整可复制Prompt，必须包含主体、空间、姿态、手部、道具、构图、焦点景深、曝光、逐镜灯光、色彩材质和连续性。

【首帧负面Prompt】

【首帧输出规则】
比例、分辨率、构图、不可裁切、后期留白、身份和灯光优先级。

【结束帧合同】
- 精确发生时间：
- 动作完成程度：
- 人物最终姿态、朝向和视线：
- 左右手最终位置：
- 道具最终位置和状态：
- 摄影机终点和最终构图：
- 最终焦点和景深：
- 最终曝光与灯光状态：
- 允许残余运动：
- 稳定停留：
- 下一镜继承：

【是否预制尾帧】
是 / 否；原因。

只有微动作、环境氛围或独立硬切可以不预制尾帧。下一镜依赖准确姿态、视线、手部、道具、构图、焦点或状态时必须预制尾帧。

【尾帧设计】
动作终点和下一镜继承状态。

【尾帧正向Prompt】
必须保持首帧身份、场景、主光世界位置、色温、白平衡、曝光和材质不变，只改变规定动作结果。

【尾帧负面Prompt】

【尾帧输出规则】

【图生图修改Prompt】
保持身份、场景、构图、焦点、曝光和灯光，只修改指定内容。

【局部修复Prompt】

【视频动作摘要】
概括时间轴动作、摄影机和尾帧，不在此重新设计人物和场景。

【连续性锚点】

【稳定替代】
补尾帧 / 抽尾帧续拍 / 分层合成 / 遮挡切换 / 两段硬切 / 固定镜头 / 后期效果。
```

## 批量规则

一次性输出整片镜头。不得每输出一镜就要求用户确认。
