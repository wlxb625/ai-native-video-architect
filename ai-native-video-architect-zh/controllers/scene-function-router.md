# Scene Function Router V4.5

## 目标

在`NARRATIVE_LOCK`和`PROJECT_VISUAL_STRATEGY`成立后，为每个Shot判断主场景功能与可选次场景功能，并把功能转译为导演、摄影、灯光、表演、Control Frame和Prompt的执行优先级。

本模块只作用于Shot层，不新增顶层工作模式，不改变剧本事实，不将任何功能绑定为固定风格。

## 接入位置

```text
NARRATIVE_LOCK
→ PROJECT_VISUAL_STRATEGY
→ Shot拆解
→ SCENE_FUNCTION_ROUTING
→ DIRECTOR_INTENT
→ CAMERA / LIGHTING / PERFORMANCE
→ CF与Prompt编译
```

不得在剧本尚未成立时用功能标签限制开放创作。单张图片或单镜头任务可以建立局部功能判断，但不得伪称全片已经完成路由。

## 必读

路由前读取：

- `references/scene-function-taxonomy.md`；
- 当前`NARRATIVE_LOCK`；
- 当前`PROJECT_VISUAL_STRATEGY`；
- 当前Shot的开始状态、主要动作、结束状态和时长。

## 路由步骤

### 1. 先问镜头改变了什么

从以下内容中找出本镜的唯一主要贡献：

- 新事实或新动作；
- 人物关系变化；
- 情绪累积或释放；
- 世界尺度或规则变化；
- 观众认知变化；
- 空间、氛围或形式体验；
- 过渡和节奏功能。

不能用“好看、电影感、华丽、忧伤”代替功能判断。

### 2. 选择主功能

主功能必须对应本镜最不可替代的观众结果。删除该功能后若镜头仍然完成同一任务，说明主功能选择错误或镜头冗余。

### 3. 判断是否需要次功能

只有在第二功能确实增强同一镜头任务、且不与主功能争夺同等优先级时才填写。次功能为空是正常状态。

### 4. 写剧本证据

至少引用一个可见事件、人物状态、信息释放或环境变化。禁止只写“符合整体风格”。

### 5. 排序信息、情绪和奇观

必须明确例如：

```text
信息 > 情绪 > 奇观
情绪 > 信息 > 奇观
奇观 > 情绪 > 信息
```

顺序决定镜头距离、焦点、光线、背景复杂度和Prompt密度。不得在最终Prompt中让低优先级元素压过高优先级元素。

### 6. 定义阅读顺序

- `first_read`：缩略图或第一眼应看见什么；
- `second_read`：继续观看后发现什么；
- `final_reveal`：本镜最终留下的理解或情绪。

不需要所有镜头都有复杂三层揭示，但必须保证第一眼不误读核心任务。

### 7. 写执行偏向

功能标签不直接给出固定景别、色彩和构图，而是向现有控制器传递重点：

- 摄影要优先看清动作、关系、空间还是尺度；
- 灯光要优先保证哪一块可读；
- 表演要突出动作阶段、内外矛盾还是释放；
- 背景应压迫、托举、中性、隐藏还是承担变化；
- 材质和色彩是否需要唯一锚点、冷暖分隔或低干扰；
- 图片Prompt和视频Prompt分别必须明确什么。

### 8. 写不得牺牲项

至少包含与本镜相关的：

- 剧情事实；
- 人物身份；
- 动作因果；
- 关系方向；
- 情绪连续性；
- 空间轴线；
- 画幅和平台可读性。

## 主功能对执行器的影响

### NARRATIVE_ADVANCE

- 摄影：动作、道具和空间关系优先；
- 灯光：关键接触区和结果状态必须清楚；
- 表演：动作阶段明确，避免装饰性姿势；
- Prompt：写清动作前后可见差异，奇观不得遮挡事实。

### SPECTACLE_IMPACT

- 摄影：大形、尺度、视觉路径和主体位置优先；
- 灯光：最强光色与奇观或事件核心对齐；
- 表演：人物状态简洁、可作为尺度与精神中心；
- Prompt：结构化华丽，控制微粒和高频细节。

### EMOTIONAL_RESONANCE

- 摄影：关系距离、未完成动作、手部与视线优先；
- 灯光：服务关系分隔或靠近，不做无来源煽情；
- 表演：可见泄漏、动作残留、内外矛盾；
- Prompt：道具自然化，检查公益广告和商品陈列风险。

### ATMOSPHERIC_IMMERSION

- 摄影：空间层次、观看关系与时间感优先；
- 灯光：真实光源与空气透视；
- 表演：人物可弱化，空镜必须写环境节奏；
- Prompt：背景大形和环境行为不可泛化。

### SYMBOLIC_METAPHOR

- 摄影：核心关系和母题重复优先；
- 灯光与色彩：符号功能明确但不字面化；
- 表演：人物行动必须与隐喻有关；
- Prompt：限制母题数量，定义替代视觉语法。

### HOOK_REVERSAL

- 摄影：第一眼和最终揭示的信息层级；
- 灯光：隐藏但不抹除异常；
- 表演：人物知道多少必须明确；
- Prompt：不能提前暴露或完全看不见关键证据。

### CATHARTIC_RELEASE

- 摄影：开始受压与结束落点；
- 灯光：强化行动结果而不是凭空神化；
- 表演：重心、姿态和呼吸完成释放；
- Prompt：避免只有英雄海报姿势。

### HEALING_SOOTHING

- 摄影：安全距离、陪伴关系和稳定节奏；
- 灯光：真实柔和，不等于统一暖黄；
- 表演：小幅动作和关系回应；
- Prompt：保留生活痕迹与视觉休息区。

### SUSPENSE_OPPRESSION

- 摄影：遮挡、未知区、威胁方向和观众位置；
- 灯光：暗部有结构，关键异常可追踪；
- 表演：人物察觉程度与观众信息差；
- Prompt：控制噪点和无意义黑暗。

### ABSTRACT_STREAM

- 摄影与构图：服从内部形式规则；
- 灯光与材质：按阶段变化，不随机切换；
- 表演：可以非现实，但状态演变清楚；
- Prompt：写明模式、方向、重复和形式高潮。

## 功能冲突处理

出现以下情况优先拆镜或重排：

- 核心动作需要立即看清，但同镜又要求完全隐藏；
- 情绪共鸣依赖近距离微表情，但奇观要求人物极小；
- 悬疑需要暗部隐藏，叙事推进却依赖暗部精确道具；
- 一个短镜头同时要求反转、觉醒、情绪崩溃和世界异变；
- 画幅或手机端缩略图无法同时承载全部信息。

不得通过无限加长Prompt解决结构冲突。

## 画幅适配

功能先于画幅，但构图必须根据当前输出条件重建：

- 16:9可利用横向关系、环境延展、对峙和并置；
- 9:16可利用垂直压迫、人物与高空关系、纵向移动和手机占屏；
- 1:1或其他比例必须重新分配人物占比、负空间和视觉路径。

画幅是当前任务参数，不得写成Skill通用默认。Prompt中的比例说明不能替代外部平台的实际宽高比参数。

## 输出要求

Shot总表可以保持简洁，但逐镜制作卡与CF必须能够追溯到完整功能判断。标签不得只存在于表格中而没有进入摄影、灯光、表演和Prompt。
