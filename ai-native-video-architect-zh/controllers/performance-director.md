# Performance Director V4.4

## 目标

把抽象情绪转化成演员可执行、模型可观察、相邻镜头可连续的表演。禁止只写“悲伤、害怕、震惊、愤怒”。

表演控制遵循：

```text
人物当下目标
+ 内部情绪
+ 对外策略
+ 情绪矛盾
+ 可见泄漏
+ 身体与呼吸
+ 时间轴变化
+ 收住状态
```

## 一、表演核心合同

每个以人物情绪为主要信息的Shot必须建立：

```yaml
performance_direction:
  character_id:
  scene_objective:
  immediate_intention:
  inner_emotion:
  outer_strategy:
  emotional_contradiction:
  intensity_start: 0-5
  intensity_end: 0-5
  gaze_target:
  face_baseline:
  body_baseline:
  leakage_cues: []
  emotion_beats: []
  forbidden_overacting: []
  end_performance_state:
```

### 解释

- `scene_objective`：人物想得到或避免什么；
- `immediate_intention`：本镜头正在做什么，例如隐藏、试探、说服、拒绝、确认；
- `inner_emotion`：真实感受；
- `outer_strategy`：人物希望别人看到的状态；
- `emotional_contradiction`：内外不一致产生戏；
- `leakage_cues`：情绪从眼神、呼吸、手指、肩膀等位置泄漏；
- `end_performance_state`：下一镜必须继承的可见情绪状态。

## 二、可观察表演通道

### 眼睛与视线

写清：

- 注视对象和视线落点；
- 是否回避、追随、失焦、重新聚焦；
- 上下眼睑张力；
- 眨眼频率与具体时点；
- 是否有泪水、眼眶湿润或眼神光变化；
- 禁止“眼神复杂”之类不可执行描述。

### 眉毛与额头

写清内眉、外眉、紧张程度和变化幅度。默认细微，不同时大幅抬眉和皱眉。

### 嘴唇、下颌与吞咽

写清：嘴唇放松、抿紧、轻颤、张开多少；下颌是否锁紧或放松；是否有一次吞咽。禁止无台词时嘴部自行说话。

### 呼吸与胸腔

写清：浅、深、屏住、恢复；胸腔或肩部起伏幅度；发生在哪个时间点。呼吸是表演节奏，不是每镜都必须夸张可见。

### 姿态与重心

写清：脊柱、肩膀、头部、骨盆和脚部重心；身体是靠近、退缩、冻结、坍塌还是重新站稳。

### 手部与手指

写清左右手位置、接触对象、手指张力和动作幅度。情绪泄漏优先使用一次小动作，不要让手持续无意义摆动。

## 三、情绪节拍

4—6秒镜头默认只允许：

- 一个主要情绪转折；
- 1—3个可见微动作；
- 一次呼吸变化；
- 一个清楚的结束状态。

示例：

```yaml
emotion_beats:
  - time: 0.0-1.2
    state: 表面平静
    visible_cues: 视线固定，肩膀不动，浅呼吸
  - time: 1.2-3.5
    state: 察觉异常
    visible_cues: 眨眼停顿，视线重新聚焦，右手食指轻微收紧
  - time: 3.5-5.0
    state: 压住恐惧
    visible_cues: 嘴唇抿紧，下颌轻锁，保持不后退
```

不要在五秒内安排“平静→怀疑→恐惧→哭泣→愤怒→释然”。复杂变化必须拆镜或延长时长。

## 四、强度标尺

- 0：无可见情绪，功能性动作；
- 1：只有一个细微泄漏；
- 2：近景可读，但人物仍可控制；
- 3：身体和面部均明显变化；
- 4：接近失控，但动作仍符合人物；
- 5：完全爆发，只用于有铺垫的高潮。

相邻镜头强度变化通常不超过2级，除非有明确突发事件。不得每个镜头都处于4—5级。

## 五、内外矛盾优先

更真实的表演通常不是情绪直接外放，而是人物在做某件事：

- 害怕但假装冷静；
- 悲伤但拒绝被看见；
- 愤怒但必须保持礼貌；
- 爱意但不敢靠近；
- 羞耻却努力解释；
- 崩溃后强行恢复功能状态。

Prompt要写“人物为什么控制自己”和“控制失败从哪里泄漏”，而不是堆叠形容词。

## 六、哭戏控制

哭泣不是默认情绪表达。需要哭戏时先选择类型：

- 眼眶湿润但不落泪；
- 单颗泪水，面部基本不动；
- 呼吸失衡但努力不发声；
- 快速擦掉泪水并恢复；
- 真正崩溃，身体和声音同时失控。

必须写清泪水出现时点、眼神是否移动、呼吸和手部动作、最后收住状态。禁止连续生成大量泪水、夸张抽泣、脸部随机扭曲和无原因张嘴。

## 七、表演与镜头、灯光协同

- 眼神是主要信息时，镜头和灯光必须让双眼可读；
- 身体冻结、退缩或重心变化时，景别必须看见躯干或脚部；
- 克制情绪优先固定镜头或低幅度推进；
- 强烈运镜只在人物认知或关系发生结构变化时使用；
- 阴影可以隐藏一部分表情，但必须保留至少一个泄漏通道；
- 音乐不能替代演员表演，重要停顿可保留呼吸和环境音。

## 八、非人物主体

机器人、面具、玩偶、动物或无脸角色也要有表演通道：

- 头部朝向、身体角度、运动节奏；
- LED、屏幕、灯光或机械部件状态；
- 距离和停顿；
- 道具接触；
- 声音和环境反馈。

不得强迫无脸角色使用人类眉眼嘴部描述。

## 九、硬失败

- 只有情绪标签，没有可见动作；
- 内部情绪、外部策略和动作互相矛盾；
- 五秒镜头包含过多情绪阶段；
- 角色上一镜克制，下一镜无事件直接嚎啕大哭；
- 每个情绪都用瞪眼、皱眉、张嘴；
- 无台词人物嘴部持续说话；
- 呼吸、手指、肩膀和头部同时高幅度运动；
- Prompt要求微表情，但镜头太远或脸被遮挡；
- 结尾没有可继承的表演状态。
