# Temporal Visual Orchestration Benchmark 001｜外部三镜生成测试包

## 1. 测试定位

本测试包来自内部基准项目《慢一秒》，只验证连续三镜中摄影机时序角色能否自然完成：

```text
SH-03 LEAD（摄影机先于人物发现危险）
→ SH-04 RESIST（摄影机保持距离并抵抗动作冲击）
→ SH-05 FOLLOW（结果形成后摄影机才靠近人物）
```

本包不是现实主义项目模板，不向核心Skill输入固定雨夜、骑手、车辆、纸风车、摄影机角色或灯光方式。

当前状态：

```yaml

external_generation_completed: false
strong_gate_passed: false
```

未获得真实生成结果前，只能称为可执行测试包，不得称为外部验证通过。

---

## 2. 本轮唯一验证目标

测试三个相邻镜头能否在同一空间、人物和事件中切换摄影机关系，同时保持：

- 人物、车辆、纸风车和道路空间事实连续；
- 危险信息先被观众看见，再被人物处理；
- 动作高潮中摄影机不抢表演、不英雄化人物；
- 危险结束后摄影机靠近具有明确时点；
- 灯光和天气不随机响应情绪；
- 三镜的流畅来自信息、空间、运动、声音和视线接力，而不是材质奇观。

本轮不验证完整成片，不扩展核心字段，不根据单次模型失败修改全局规则。

## 5. 共享视觉与声音基准

### 5.1 视觉基准

- 当代现实主义数字电影质感；
- 关键空间关系和动作优先于氛围装饰；
- 雨夜暗部保留道路、轮胎、手部和人物轮廓信息；
- 街灯和车灯可形成局部反射，但不产生神圣轮廓光；
- 色彩以湿冷灰蓝、道路中性暖光和交通信号色构成；
- 不增加粒子、光尘、能量流、夸张雾气或广告式车漆高光；
- 画面允许真实雨丝和轮胎水雾，但不可遮挡空间关系。

### 5.2 声音基准

声音后期独立完成，不依赖视频模型生成准确音轨。

共享声音资产：

- 稳定雨声；
- 远处城市交通底噪；
- 电动车低频电机声；
- 货车轮胎压过湿路面的低频声；
- 一次短促喇叭；
- SH-04一次制动摩擦与水声；
- SH-05逐渐恢复的呼吸与远去车声。

音乐默认不使用。需要音乐时只允许低存在感持续音，不得替代危险信息和人物呼吸。

# 11. 生成失败时的降级顺序

## 11.1 SH-03失败

- 摄影机甩动：降低横移幅度，延长侧移时间；
- 货车突然出现：将货车前灯和部分车头预先放入首帧边缘；
- 骑手提前反应：删除人物情绪词，只保留视线结束合同；
- 三方关系不清：增加空间更宽的控制帧，不继续增加动态描述。

## 11.2 SH-04失败

- 夸张漂移：改为更低速度、减少后轮侧滑，必要时拆为“开始制动”和“停稳”两段；
- 多对象漂移：货车与骑手分层生成，后期合成；
- 手脚错误：使用中全景并局部修复尾帧；
- 摄影机随机后退：改为固定机位版本，先验证动作与空间，再单独测试轻微后撤；
- 无法维持安全距离：扩大场景比例，降低车辆逼近幅度。

## 11.3 SH-05失败

- 摄影机提前推进：首段明确固定0.8秒，或拆成固定镜头与缓推镜头；
- 变成英雄特写：缩短推进幅度，保持车把和纸风车可见；
- 环境情绪化变化：完全锁定灯光、雨量和信号灯；
- 人物表演过度：只保留视线、右手张力和一次呼吸。

降级后的目标仍是验证导演关系，不追求复杂度。
