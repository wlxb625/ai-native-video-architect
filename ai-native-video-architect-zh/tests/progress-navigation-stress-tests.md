# Progress Navigation Stress Tests

以下场景必须得到预期结果。

## 首次调用与阶段定位

1. 用户只说“帮我做个短视频” → 显示`S00 创作需求`，不得直接进入剧本或资产。
2. 用户已经给出类型、情绪、主角、时长和画幅，但未选故事 → 可标记S00完成，进入`S01 创意方向`。
3. 用户提供完整故事梗概 → 显示从`S03 剧本或视觉脚本`进入，并说明跳过依据。
4. 用户上传已确认完整剧本 → 显示`S04 剧本拆解`，不得重新要求从S00回答全部问题。
5. 用户上传角色、场景和道具图 → 显示`S08 资产审核`，不得直接写“资产已完成”。
6. 用户提供完整镜头表但无角色和场景资产 → 显示返回`S06 资产计划`，保留镜头意图。
7. 用户提供完整资产和分镜帧 → 显示`S11 核心样片`，不得直接批量生成。

## 完成状态真实性

8. 只提供了创意方向但用户未选择 → `S01`保持当前，不得标记完成。
9. 已输出剧本但用户尚未确认 → `SCRIPT_CONFIRMATION`未通过，S03不得显示完成。
10. 用户回复“剧本可以” → S03完成，下一步显示S04。
11. 资产评分82 → 显示`△ S08资产审核`，只允许Core Sample，不得进入正式分镜批量生产。
12. 资产评分91但存在AF3场景布局硬失败 → S08失败，不得标记通过。
13. 分镜只完成一半 → S09或S10保持当前，不能因已经输出部分镜头标记整个阶段完成。
14. Core Sample人物换脸 → S11未通过，明确返回S07或S10修复。

## 用户决定与下一步

15. 当前需要方向选择 → `需要你确认`必须写明选择哪个方向。
16. 当前步骤不需要用户决定 → 写“无，本轮可直接继续”，不得让用户无意义回复“可以”。
17. 资产确认门 → 明确需要确认角色、服装、场景、道具和状态版本。
18. 分镜确认门 → 明确需要确认镜头数量、动作、构图、运镜和难度。
19. 阶段回退 → 必须说明保留哪些已通过成果、只修哪一层、完成后返回哪一阶段。

## DIAGNOSE与TRANSFORM

20. 用户说“只诊断这个分镜” → 显示诊断模式和原成果所属S09或S10，不自动推进。
21. 用户说“保留剧本，只改视觉风格” → 显示TRANSFORM、原阶段、必须保护剧本和返回S05。
22. 用户说“改掉结尾” → 明确这是剧本层修改，返回S03并使后续拆解、资产和分镜相关状态待重新验证。
23. 用户只修改某一道具颜色 → 返回S06/S07更新道具版本，并标记依赖镜头需要重新确认，不推翻无关资产。

## 进度显示质量

24. 进度提示超过主要交付内容长度 → FAIL + PROGRESS_OVERLOAD。
25. 进度提示展示冗长内部推理 → FAIL + INTERNAL_REASONING_LEAK。
26. 使用“已完成”但没有输出、材料或确认依据 → FAIL + FALSE_COMPLETION。
27. 用户要求不显示进度 → 后续可隐藏，直到用户主动询问。
28. 用户问“现在到哪一步了” → 必须显示当前阶段、完成项、本轮交付、确认项和下一步。
29. 每次普通句子都重复完整14阶段 → FAIL + PROGRESS_SPAM。
30. 首次调用和阶段切换显示紧凑5—6行导航 → PASS + PROGRESS_VISIBLE。

## 剧本与资产顺序

31. 只有一句概念就开始批量写角色、场景、道具和分镜Prompt → FAIL + SCRIPT_GATE_BYPASS。
32. 无对白意识流作品有完整视觉脚本 → PASS，可进入S04，不强制传统对白剧本。
33. 剧本确认后先拆解资产，再建立视觉圣经和资产计划 → PASS + SCRIPT_FIRST_ASSET_READY。
34. 资产先于正式分镜帧和视频，但晚于剧本与拆解 → PASS + CORRECT_ASSET_FIRST_ORDER。
35. 已有剧本却再次要求填写全部创作问卷 → FAIL + REDUNDANT_INTAKE。

## 验收标记

实现至少包含以下协议词：

- `Progress Navigation Contract`
- `current_stage`
- `completed_outputs`
- `user_decision_if_needed`
- `next_stage`
- `STORY_DIRECTION_CONFIRMATION`
- `SCRIPT_CONFIRMATION`
- `ASSET_CONFIRMATION`
- `STORYBOARD_CONFIRMATION`
- `CORE_SAMPLE_GATE`
- `FALSE_COMPLETION`
