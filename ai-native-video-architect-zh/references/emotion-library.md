# Emotion and Micro-Performance Library V4.4

## 使用方式

本库不是固定模板。先确定人物目标、内外矛盾和强度，再选择少量可见线索。每个短镜头通常使用：1个眼神线索、1个嘴或下颌线索、1个身体或手部线索、0—1个呼吸线索。

## 通用维度

```yaml
emotion_profile:
  inner_state:
  outer_strategy:
  gaze:
  eyelids_and_blink:
  eyebrows:
  mouth_and_jaw:
  breathing:
  posture_and_weight:
  hands:
  movement_rhythm:
  camera_fit:
  lighting_fit:
  avoid:
```

## 1. 压住恐惧

- 内部：危险已经被确认；
- 外部策略：不让对方或自己看出慌乱；
- 眼神：短暂停顿后重新聚焦，不持续乱瞟；
- 眼睑：略微睁大，眨眼减少；
- 嘴与下颌：嘴唇轻抿，下颌轻锁；
- 呼吸：变浅，必要时短暂屏住；
- 身体：肩背变硬，重心略后移但不立刻逃跑；
- 手：一根或两根手指收紧；
- 适合镜头：中近景固定或极慢推进；
- 适合灯光：眼睛可读的侧光或顶部冷光；
- 避免：大幅瞪眼、张嘴、尖叫、全身持续发抖。

## 2. 隐忍悲伤

- 内部：失去已经发生；
- 外部策略：继续完成眼前任务；
- 眼神：看向固定物件或稍微回避他人；
- 眼睑：眨眼变慢，眼眶可轻微湿润；
- 嘴与下颌：嘴角不下撇，嘴唇轻压；
- 呼吸：一次较深吸气后恢复浅呼吸；
- 身体：胸口略收，肩膀轻沉；
- 手：握住衣角、杯沿或道具后又松开；
- 适合镜头：中景观察身体，近景只用于泄漏瞬间；
- 避免：默认落泪、抽泣、皱脸、仰头闭眼。

## 3. 单颗泪水但保持倔强

- 起点：目光稳定，表情基本不动；
- 变化：眼眶积水，单颗泪在明确时点落下；
- 身体：头部和视线不追随泪水；
- 收住：一次深呼吸，下巴略抬，恢复功能状态；
- 避免：连续泪流、嘴部扭曲、随机擦脸、哭笑切换。

## 4. 隐忍愤怒

- 内部：受到侵犯或不公；
- 外部策略：保持礼貌或控制局面；
- 眼神：持续注视，不频繁转移；
- 眉：内眉轻压，不夸张皱眉；
- 嘴与下颌：下颌肌轻紧，台词前短暂停顿；
- 呼吸：鼻腔缓慢呼气；
- 身体：脊柱更直，动作变少；
- 手：握持力度增加后停止；
- 避免：脸红、咆哮、猛拍桌、快速环绕镜头，除非剧情已经进入爆发。

## 5. 羞耻与回避

- 内部：害怕被评价或暴露；
- 外部策略：缩小存在感或解释；
- 视线：短暂接触后落向地面或侧面；
- 眉与嘴：眉部轻紧，嘴唇在开口前轻微停顿；
- 身体：胸口微收，肩膀靠近身体；
- 手：整理衣袖、遮挡或触碰自身；
- 避免：夸张低头、扭捏笑、持续摆弄双手。

## 6. 怀疑与验证

- 内部：信息不一致；
- 外部策略：不立即表态，先确认；
- 视线：从人物转向证据，再回到人物；
- 眨眼：在发现不一致时一次停顿；
- 嘴：轻微闭合或短促吸气；
- 身体：头部小角度偏转，重心保持；
- 手：动作停止在半途；
- 适合镜头：焦点转移、视线匹配或静止近景；
- 避免：歪头卖萌、夸张眯眼、连续左右看。

## 7. 爱意但不敢靠近

- 内部：想靠近；
- 外部策略：保持普通距离；
- 视线：看向对方后在被发现前移开；
- 眼睑：放松，眨眼自然；
- 嘴：非常短暂的微笑后收回；
- 身体：上身轻微前倾后停止；
- 手：想触碰但停在合理距离；
- 避免：持续甜笑、夸张害羞、无原因慢动作转圈。

## 8. 疲惫麻木

- 内部：情绪资源耗尽；
- 外部策略：只维持最低功能；
- 视线：固定、略失焦，重新聚焦较慢；
- 眼睑：略沉，眨眼慢；
- 嘴：放松，不刻意下垂；
- 呼吸：缓慢、浅；
- 身体：肩部下沉，动作启动延迟；
- 手：自然垂落或重复机械动作；
- 避免：闭眼打哈欠、夸张驼背、一直摇头。

## 9. 崩溃前兆

- 内部：控制即将失败；
- 外部策略：仍试图维持；
- 视线：固定过久或短暂失焦；
- 眼睑：细微颤动；
- 嘴与下颌：嘴唇压紧后松开，下颌失去稳定；
- 呼吸：一次不完整吸气；
- 身体：肩膀出现一次不受控起伏；
- 手：握住支撑物；
- 避免：直接进入大哭或跪地，除非下一镜专门承担爆发。

## 10. 真实崩溃

- 必须有前置积累；
- 表情、呼吸、声音和身体不能同时随机失控；
- 先确定主通道，例如呼吸失衡、身体坍塌或哭声；
- 镜头最好保持稳定，让表演承担冲击；
- 结尾必须给出疲惫、停顿、离场或被打断的状态；
- 避免无限升级、持续尖叫、面部扭曲和反复拍打。

## 11. 释然

- 内部：接受无法改变的事实或做出选择；
- 外部：不一定微笑；
- 视线：从回避转为稳定；
- 嘴与下颌：下颌松开，嘴唇恢复自然；
- 呼吸：完整呼气；
- 身体：肩膀下降，重心重新稳定；
- 手：松开此前握紧的物件；
- 避免：突然明亮大笑、无原因暖光覆盖全场。

## 12. 冷静失控

- 内部：决定执行危险或不可逆行动；
- 外部：异常平静；
- 视线：精确锁定目标；
- 面部：变化很少；
- 呼吸：恢复均匀；
- 身体：动作变得直接、无多余犹豫；
- 手：稳定完成一个动作；
- 镜头：静止或精确跟随；
- 避免：疯笑、瞪眼、快速剪辑代替选择。

## 组合原则

优先组合“情绪 + 控制策略”，例如：

- 恐惧 + 保持专业；
- 悲伤 + 照顾别人；
- 愤怒 + 必须礼貌；
- 爱意 + 害怕越界；
- 羞耻 + 努力解释；
- 释然 + 仍然痛苦。

组合后只保留最能被镜头读到的少量线索，禁止把两个模板全部拼接。
