# Continuity and Repair System

## 目标

在Prompt生成前维护全片唯一的连续性台账，并在真实生成后修复上下视频不连贯、多角度穿帮、人物变脸、场景重建、道具消失、手部错误、色调跳变和画质问题。

核心原则：

> 连续性台账是跨镜剧情状态的唯一事实源。Shot卡、CF、图片Prompt、视频Prompt和评估模块只引用或更新它，不各自建立另一套状态记录。

## 一、连续性台账

每个项目建立一个`CONTINUITY_LEDGER`。第一镜从`PROJECT_INITIAL_STATE`开始，其余镜头从上一镜唯一`End State ID`继承。

```yaml
continuity_ledger_entry:
  ledger_id:
  shot_id:
  source_end_state_id:
  inherited_story_facts:
  character_knowledge_and_intention:
  action_phase_and_completion:
  visible_character_state:
    position_orientation_pose_gaze:
    breath_weight_hands_and_contacts:
  prop_state_and_ownership:
  costume_damage_wetness_stamina_and_accumulation:
  scene_geography_axis_and_screen_direction:
  camera_focus_light_weather_time_and_sound_state:
  emotional_and_relationship_residue:
  new_change_in_this_shot:
  facts_that_must_not_reset: []
  exact_end_state:
  end_state_id:
  next_shot_required_inheritance: []
  intentional_discontinuity:
  discontinuity_reason:
```

字段可以在最终交付中用自然语言呈现，不要求机械输出YAML；但每个连续Shot必须能够追溯到唯一台账条目。

## 二、模块引用规则

- Shot卡：引用`ledger_id`和`source_end_state_id`，记录本镜新变化，并把精确尾态写回台账；
- CF：读取台账中的可见人物、道具、空间、灯光和累积状态；
- 视频Prompt：从台账起态开始，只推进本镜新变化，并抵达台账尾态；
- 时空编排：只选择跨系统关系与接力通道，不复制台账事实；
- 摄影、灯光、表演模块：使用台账起态和尾态作为连续性边界，不另建人物或环境状态链；
- 完整性检查：核验引用关系和状态无重置，不要求多份重复记录。

## 三、剧情状态不得重置

连续镜头必须保证：

- 人物不会忘记已经知道的信息；
- 已经作出的决定不会无原因重新犹豫或再次执行；
- 动作按准备、接触、进行、完成和完成后残留推进；
- 已经拿起、放下、打开、破坏或交付的道具不会恢复旧状态；
- 伤损、污渍、湿水、服装变化、体力消耗和其他累积状态持续；
- 人物站位、朝向、视线、手部接触和重心不会无原因返回初始值；
- 场景入口出口、地标、轴线、屏幕方向和光源位置保持可理解；
- 情绪从上一镜尾态继续，不在每镜重新从相同强度开始；
- 上一镜尾态能够直接进入下一镜首态，或明确说明跳切、省略和有意断裂。

改变摄影角度、景别和构图，不等于改变故事事实。

## 四、生成前使用

每个镜头进入CF或Prompt生成前：

1. 读取`source_end_state_id`；
2. 确认本镜唯一剧情任务和唯一新增变化；
3. 检查镜头设计是否与继承状态冲突；
4. 决定是否需要上一镜稳定尾帧、首尾帧、硬切、遮挡或分层；
5. 生成本镜CF与Prompt；
6. 写出可见、可截图、可验证的精确尾态；
7. 将尾态登记为新的`end_state_id`。

若一个镜头需要同时重建人物、道具、空间、动作和情绪，优先拆镜，不通过继续加文字掩盖问题。

## 五、抽尾帧续拍

适用于同一动作未完成、人物继续行走或说话、运镜继续推进、同场景接近一镜到底。

步骤：

1. 提取上一段最后一个稳定帧，避开运动模糊和形变帧；
2. 将其作为下一段唯一首帧；
3. 引用对应`end_state_id`；
4. 只描述尚未完成的动作；
5. 保持人物、服装、道具、背景、光线、色调和机位关系；
6. 指定新的精确尾态并写回台账。

## 六、硬切新镜头

适用于换景别、换机位、换角度、切人物反应或道具特写。

硬切可以改变观看位置，但必须从同一台账状态建立新首帧，保留：

- 人物知识与目的；
- 动作完成度；
- 人物站位、朝向、视线和接触；
- 道具状态与归属；
- 服装、伤损、湿水和累积变化；
- 场景地标、轴线和屏幕方向；
- 光源世界位置、天气与时间；
- 情绪和关系残留。

## 七、多角度防穿帮

- 第一个空间锚定镜头优先全景或中远景；
- 保留人物、地面、背景地标和关键道具关系；
- 多人场景先锁定站位图；
- 换角度时只改变摄影机，不改变台账中的空间事实；
- 正反打保持视线方向、道具归属、说话顺序和人物已知信息；
- 避免连续极近特写后切到没有空间依据的新角度。

## 八、常见生成修复

### 人物变脸

返回面部身份资产，优先局部修复或重做单帧，不继续往Prompt堆外貌词。

### 服装漂移

返回服装或状态板，锁定领口、袖口、层次、污渍、破损和湿水阶段；不得恢复初始洁净状态。

### 场景漂移

回到场景主布局和正确机位，保留入口出口、地标、屏幕方向、天气、时间和世界光源。

### 道具变形

使用道具结构、尺寸和交互参考；状态变化优先首尾帧或分层生成；同时检查归属、开合、破损、消耗和手部接触。

### 手部错误

优先局部重绘或切到更稳定景别，不改变已经成立的道具归属、动作阶段和下一镜尾态。

### 台词错误

单镜只保留一个说话主体和一句准确台词；下一镜继承谁说过、谁听见以及当前反应阶段。

## 九、局部修改原则

```text
保持原图构图、人物、背景、光线、色调和质感不变。
只修改指定区域：原内容 → 新内容。
新内容的光线、透视、材质和边缘与原图融合。
其他区域零变化。
```

夜景降噪和4K增强只能提升质量，不能重绘面孔、改变姿势、重新布光或修改白平衡与颜色关系。

## 十、连续性失败判定

以下任一情况不是普通画面瑕疵，必须回到台账或Shot设计：

- 每镜重新介绍人物和场景，像独立短片；
- 已完成动作在下一镜重新开始；
- 人物知识、目的、关系或情绪无原因回退；
- 道具、伤损、服装、湿水或接触状态被重置；
- 镜头只保持相似颜色，却丢失事件因果和空间事实；
- 为追求单镜奇观改变上一镜已经成立的事实；
- 上一镜结束帧合同没有成为下一镜起态；
- Shot卡、CF和Prompt引用了不同版本的状态。

## 十一、修复优先级

```text
修正唯一连续性台账或Shot继承关系
→ 局部修复
→ 图生图修复单帧
→ 重做单个首帧或尾帧
→ 重做单个视频镜头
→ 回到对应资产
→ 最后才回退场景或视觉圣经
```

不得因为一个局部错误推翻全部资产和分镜，也不得用后期掩盖已经破坏剧情因果的状态重置。
