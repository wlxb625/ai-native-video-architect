# Performance Prompt Compiler V4.4

## 目标

将人物目标、情绪矛盾、微表情、身体语言和时间轴编译进静态控制帧Prompt与视频Prompt，使表演可生成、可观察、可连续。

编译前读取：

- `controllers/performance-director.md`；
- `references/emotion-library.md`；
- `controllers/camera-director.md`；
- `controllers/lighting-director.md`。

## 一、Prompt优先级

模型容易忽略过长且无序的信息，因此按以下优先级组织：

1. 人物当前可见状态和唯一情绪转折；
2. 视线与主要表情泄漏；
3. 身体重心、手部和呼吸；
4. 摄影机如何让这些细节可读；
5. 灯光如何保留关键表演区域；
6. 禁止夸张和随机动作。

同一镜头不要同时控制十多个面部部位。只写对剧情有用的变化。

## 二、静态图片Prompt

图片只能捕捉一个情绪时点，必须写可见状态：

```text
人物正在努力保持镇定，视线固定在镜面中央，眼睑略微绷紧，嘴唇轻抿，右手食指在洗手台边缘收紧，肩背轻微僵硬；没有哭泣、没有张嘴、没有夸张惊恐表情。
```

禁止只写“她内心恐惧”“复杂情绪”。内部情绪必须通过姿态、眼神、嘴、呼吸可见结果表达。

### 首帧

首帧写基线状态和动作前准备，不提前完成情绪转折。

### 尾帧

尾帧只改变本镜头规定的表演结果，并保持身份、场景、构图和灯光连续。

## 三、视频Prompt时间轴

每镜按时间编写：

```text
0.0—1.0秒：保持首帧状态，仅有低幅度自然呼吸；
1.0—3.2秒：视线从门把移动到门缝，眨眼动作停顿一次，右手食指轻微收紧；
3.2—5.0秒：嘴唇轻抿，下颌略微锁紧，人物不后退，最终保持压住恐惧的静止状态0.6秒。
```

要求：

- 每个变化有时间点；
- 面部、呼吸、身体和手部变化不同时高幅度发生；
- 结束状态可截图并供下一镜继承；
- 情绪强度变化符合事件和前后镜头。

## 四、长提示词模式

用户或目标平台允许长Prompt时，可以输出`FULL_PERFORMANCE_PROMPT`，但仍按模块排序：

```text
角色目标与内外矛盾
→ 起始表演基线
→ 分秒情绪节拍
→ 眼神与面部
→ 呼吸与身体
→ 手部与道具
→ 摄影与焦点
→ 灯光可读性
→ 结束表演状态
→ 禁止表演
```

长Prompt不是重复同义词。每一句必须控制不同的可见变量。

平台对长Prompt理解较弱或用户未指定时，输出：

- `核心表演Prompt`：必须执行的6—10项；
- `扩展表演控制`：可选细节；
- `负面表演约束`：防止夸张和漂移。

## 五、对话与口型

有台词时：

- 只允许指定人物说指定台词；
- 台词前后的视线、呼吸和停顿清楚；
- 嘴部必须可见，镜头不能突然转背或遮挡；
- 不支持原生口型的平台转入后期，不强迫视频模型完成；
- 台词情绪由动作和语气共同表达，避免边说边进行复杂动作。

## 六、哭戏编译

先确定：是否落泪、几颗、何时出现、人物是否擦拭、是否发声、最终如何收住。示例结构：

```text
前2秒保持视线和头部不动，只见胸腔低幅度起伏；第2.5秒眼眶开始湿润；第3.5秒只有一颗泪从靠近镜头一侧眼角滑落，人物不追随泪水；第4.5秒完成一次深吸气，下颌重新锁住，保持倔强而疲惫的视线。禁止连续流泪、夸张抽泣、张嘴哭喊和面部扭曲。
```

## 七、表演负面Prompt

按当前镜头选择：

- 不要夸张瞪眼、抬眉、张嘴和摇头；
- 不要无台词口型；
- 不要持续随机眨眼；
- 不要双手无意义摆动；
- 不要头肩手同时大幅运动；
- 不要情绪瞬间跨越多个强度级别；
- 不要随机微笑、哭笑切换或商业写真表情；
- 不要泪水无限增加或改变方向；
- 不要为了表演改变人物身份、脸型和年龄。

## 八、内部冲突检查

交付前检查：

- 镜头距离是否能读到指定微表情；
- 灯光是否保留眼睛、嘴、手或呼吸所需区域；
- 情绪转折是否由事件触发；
- 图片首尾帧与视频表演时间轴是否一致；
- 上一镜结束强度与下一镜开始强度是否衔接；
- Prompt中的“保持静止”是否与同时要求的身体动作冲突；
- 负面约束是否误杀必要动作。
