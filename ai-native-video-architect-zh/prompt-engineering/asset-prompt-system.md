# Asset Prompt System

## 目标

为S07生成完整可复制的角色、服装、场景、道具、状态和修复Prompt。每种资产调用自己的结构，不使用单一万能模板。

## 统一资产字段

每项资产至少记录：

```yaml
asset:
  id:
  name:
  purpose:
  source_scenes: []
  reference_inputs: []
  reference_roles: []
  must_preserve: []
  allowed_variation: []
  positive_prompt:
  negative_prompt:
  output_rules: []
  stable_generation_method:
  repair_prompt:
  naming_rule:
  dependencies: []
```

## 面部身份板

### 用途

锁定骨相、年龄、发际线、肤质和独特标记。

### 必须描述

- 年龄和真实生活状态；
- 脸型和下颌；
- 眉眼距离与眼型；
- 鼻梁、鼻翼和鼻头；
- 嘴唇和嘴角；
- 肤色、毛孔、细纹、区域色差；
- 轻微自然不对称；
- 发际线、鬓角和碎发；
- 稳定身份标记；
- 与其他角色的骨相差异。

### 建议视图

正面、左右四分之三、标准侧面和剧情相关细微表情。多视图不稳定时分张生成后排版。

## 生产三视图

### 固定结构

- 正面全身；
- 严格90度侧面全身；
- 背面全身；
- 同一中性站姿；
- 相同人物高度和比例；
- 头顶至脚底不裁切；
- 均匀中性光；
- 简洁背景。

不能用艺术身份板替代生产三视图。

## 发型结构板

展示正面、侧面、背面、发际线、分缝、束发或发髻结构、饰物位置和碎发分布。湿发、风吹或受损状态单独版本。

## 服装与状态板

写清：

- 内层、中层、外层；
- 领口、袖口、腰带、下摆、鞋履；
- 材质、缝线、纹样和做旧；
- 穿戴、开合和收纳逻辑；
- 污渍、破损和固定标记；
- 状态链与变化镜头。

服装状态不得只写“越来越脏”，必须定义可见版本。

## 人物细节与道具综合板

适用于需要同时理解角色轮廓、面部、手部、服装材质和随身物件的项目。可使用艺术书式排版，但不能遮挡生产信息。道具必须单独完整显示，尺寸和结构与人物持有状态一致。

## 手部与交互板

每格只展示一个接触动作，写清：

- 左右手分工；
- 工具握持位置；
- 接触点；
- 尺寸和重量；
- 重心与关节；
- 禁止穿模；
- 动作开始或结束状态。

## 姿态与连续动作板

静态姿态板用于常用站、坐、跪、俯身、持物和停顿。只有打斗、舞蹈、特效、复杂仪式等连续动作才使用4至9格故事板。

动作故事板按阅读顺序描述：起势、蓄力、启动、展开、高潮、余势、收住。每格保持人物、服装、道具、场景和光线一致。

## 场景主布局

场景Prompt公式：

```text
时代背景
+ 具体地点
+ 场景功能
+ 空间布局
+ 出入口和人物路线
+ 固定道具与地标
+ 建筑和地面材质
+ 光线方向
+ 色调
+ 摄影机和构图
+ 真实使用痕迹
+ 负面约束
```

主布局需要透视图与平面关系能够互相对应。

## 无人物空镜

先生成没有人物的场景，锁定建筑、透视、材质、光源、道具位置和纵深。正式人物分镜引用角色资产和空镜共同生成。

## 多机位场景板

当同一场景有三个以上机位时，生成正面宽景、左右侧面、侧后、低机位和高机位。所有机位只改变摄影机，不改变建筑、地面、道具和光源。

九宫多机位板可用于预演，但正式生成时优先逐机位输出清晰单图。

## 道具结构板

道具公式：

```text
道具名称
+ 时代地域文化
+ 尺寸和人体比例
+ 正侧背/底部结构
+ 材质和制作工艺
+ 使用痕迹
+ 独特标记
+ 持有和收纳逻辑
+ 状态版本
+ 中性背景
+ 负面约束
```

核心道具禁止只追求造型美感而缺少结构和使用逻辑。

## 状态链

每个状态必须：

- 使用同一身份或结构；
- 保持同一机位和比例；
- 只改变指定状态；
- 明确累积或可逆关系；
- 标出由哪个镜头产生；
- 标出后续继承范围。

## 图生图修改

修改Prompt必须先声明：保持构图、人物身份、场景、光线、色调和质感不变，只修改指定区域。说明原内容、新内容、融合光线、透视和材质。

禁止重绘整张图，除非用户明确要求重做。

## 局部修复

用户可用框线或蒙版标记区域。Prompt必须说明：删除、替换或修复哪个区域，以及其他区域完全不变。

## 降噪和4K增强

只提升清晰度、边缘、动态范围和材质细节，保持面部、姿势、构图、透视、服装、背景、光线、白平衡和色调零偏差。禁止重新布光和改变形体。

## 资产Prompt输出规则

- 一个资产一个完整复制块；
- 不把正向、负面和输出规则拆到不同位置；
- 保留详细设定和前置依赖；
- 所有资产在S07同一轮完整交付；
- 每块附稳定生成方法；
- 不要求用户逐项回报；
- 用户自审通过后直接进入下一阶段。
