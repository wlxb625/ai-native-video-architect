# Visual Style, Color and Lighting Compiler

## 色调不是单一滤镜

每个项目必须以六个核心维度建立色调：

```text
主色 + 辅助色 + 点缀色 + 色温 + 饱和度 + 明暗对比
```

并补充：白平衡、黑位、高光、肤色关系、核心道具颜色和禁止颜色。

## 场景连续性

每个分镜Prompt都必须继承：

- 相同主色体系；
- 相同白平衡基准；
- 相同色温关系；
- 相同肤色与背景关系；
- 相同黑位和高光策略；
- 点缀色只能出现在预定人物、道具、光源或情节重点。

不同时间和光源允许自然明暗变化，但不得无原因更换滤镜或让服装、肤色和核心道具跳色。

## 光影公式

```text
真实光源
+ 光线方向
+ 光线颜色
+ 照亮主体
+ 暗部层次
+ 画面情绪
+ 电影摄影质感
```

禁止只写“真实光照、电影感”。

## 常用打光选择

### 自然顺光

适合人物设定、产品、生活、教学和稳定展示。主体清楚，但戏剧性较弱。

### 侧光

适合人物情绪、古风、历史、纪录和悬疑。必须说明亮侧、暗侧与暗部细节。

### 侧逆光

适合人物登场、轮廓分离、仪式和英雄感。不能让人物正面完全死黑。

### 逆光剪影

适合背影、告别、孤独和结尾。需要看脸时补充正面暗部细节。

### 窗口光或门缝光

适合室内悬念、手部和道具特写。说明光束进入方向和照亮区域。

### 火光或烛光

适合古代夜景与仪式。暖光为局部光源，环境仍需冷色或暗色层次，禁止整画面橙黄。

### 低调高对比光

适合悬疑、秘密和压迫。低调光不等于全黑，关键人物和道具必须可读。

### 柔光

适合治愈、亲密、人物身份板。阴影柔和但仍保留脸部结构。

### 顶光

适合审问、孤独、仪式和压迫。避免眼窝完全黑死。

## 夜景与暗场规则

- 暗部保留材质和空间地标；
- 角色面部、手部和核心道具至少有一种可验证光源；
- 避免脏灰、压缩噪点、彩色斑块和死黑；
- 不使用无来源病态绿光作为“恐怖感”捷径，除非视觉圣经明确要求；
- 夜景降噪只修复噪点、边缘和色彩，不重构画面。

## 真实材质与影像质感

推荐描述：

- 真实摄影透视；
- 自然景深；
- 宽动态范围；
- 高光不过曝；
- 暗部保留细节；
- 轻微细腻颗粒；
- 克制锐化；
- 真实皮肤、衣料和道具反光。

不要把所有项目机械写成高对比、强轮廓光或超浅景深。

## 色调编译到Prompt

每条图片或视频Prompt不需要重复整份Visual Bible，但必须包含当前镜头相关的：

```text
主色关系
+ 当前光源方向和颜色
+ 主体受光区域
+ 暗部要求
+ 点缀色用途
+ 连续性句
```

## 色调硬失败

- 将主色理解为整张图单色覆盖；
- 人物肤色被背景色严重污染；
- 同一场景不同镜头白平衡随机变化；
- 点缀色大面积泛滥；
- 夜景主体完全不可读；
- 主光方向在同一空间跳变；
- 高光过曝掩盖核心信息；
- “高级感”只依靠青橙滤镜、蓝色滤镜或低曝光。
