# Video Prompt Compiler

## 目标

把已批准的首帧或首尾帧、镜头设计和动作计划编译成可用于图生视频软件的完整Prompt。

## 视频Prompt基础公式

```text
参考图或首帧说明
+ 视频类型
+ 场景设定
+ 主体人物
+ 起始状态
+ 动作过程
+ 镜头运动
+ 光线色调
+ 风格质感
+ 场景稳定要求
+ 结尾画面
+ 声音要求
+ 负面约束
```

简单理解：从哪张画面开始、谁在哪里做什么、动作和镜头怎么走、最终停在哪里、什么不能变化。

## 核心原则

1. 使用参考图作为唯一首帧；
2. 不在视频Prompt中重新设计人物和场景；
3. 一个短镜头只有一个唯一主要动作；
4. 动作必须有起势、过程和收住；
5. 镜头运动必须有起点、方向、速度、幅度和终点；
6. 结尾状态必须具体可见；
7. 环境只允许指定元素运动；
8. 负面约束针对角色、手部、道具、背景、光线、镜头和结尾。

## 图生视频通用结构

```yaml
video_prompt:
```

## 动作编译

### 起始状态

写清身体姿态、手的位置、道具接触、视线、重心和停顿。

### 起势

动作前的细微准备，例如呼吸、重心下沉、手指收紧或视线转移。不要机械要求所有动作都有夸张蓄力。

### 过程

按清楚顺序写1至3个动作节点。五秒镜头通常不应包含更多。

### 收住

写清最终姿态、手脚位置、道具状态、呼吸和停留时间。视频不能在动作中间无目标结束。

## 物理与接触

- 脚部真实接触地面；
- 重物需要双手、重心和速度；
- 手与道具接触点明确；
- 衣料和头发只发生与动作和风相关的合理变化；
- 不允许滑行、漂浮、穿模和无重量。

## 首尾帧视频

使用首帧和尾帧时：

- 开头准确继承首帧；
- 中间过程连接两帧；
- 动作有起势、过程和收住；
- 人物、服装、道具、背景、光线和色调保持一致；
- 结尾稳定停在尾帧，而不是一闪而过。

首尾帧构图差异过大时，不强迫模型连续变换，应使用硬切或拆镜。

## 硬切视频

硬切不是运镜。Prompt必须写：

- 第一机位和动作；
- 明确切点或动作节点；
- 第二机位、景别和特写内容；
- 动作在第二镜继续的剩余部分；
- 硬切前后连续性锚点；
- 禁止溶解、滑动或自动转场。

复杂硬切更稳定的方法是分别生成两段视频后剪辑，不让单次生成承担切镜。

## 环境氛围视频

无明显剧情动作时，只让指定元素轻微运动：雨、火、烟、水面、尘埃、树叶、布料或远处人群。运动克制，建筑、地面和道具稳定。

## 文生视频边界

文生视频抽卡成本高且一致性弱。正式项目优先：

```text
资产参考 → 分镜首帧 → 图生视频
```

只有概念探索或无稳定主体时才优先文生视频，并明确风险。

## 声音字段

按工具能力写：

- 环境音；
- 人物呼吸和衣料；
- 道具接触；
- 台词；
- 音乐是否进入；
- 是否需要沉默。

不支持原生声音的模型，将声音字段转入后期计划，不假装模型一定生成。

## 台词镜头

只有一个说话主体时，写明：

- 人物名称；
- 景别；
- 面部和嘴部可见；
- 视线和语气；
- 唯一台词；
- 禁止增删改词；
- 其他人物不说话；
- 镜头稳定；
- 声音清楚。

复杂对话优先分镜、分人、分句生成，再剪辑。

## 输出格式

每镜使用`templates/video-shot-prompt-block.md`，将完整正向Prompt、负面Prompt、输出规则、衔接方法和失败修复放在同一个复制块中。

## 视频Prompt硬失败

- 只写“动起来、电影感、镜头推进”；
- 未指定首帧；
- 一个五秒镜头包含过多动作与运镜；
- 只有动作，没有结束状态；
- 运镜无起点和终点；
- 背景、人物和道具稳定项缺失；
- 在视频Prompt中重新设计服装和场景；
- 首尾帧差异需要换景却要求平滑过渡；
- 声音要求与工具能力不匹配且未转为后期。
