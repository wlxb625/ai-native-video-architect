# Video Prompt Compiler

## 目标

把已批准的分镜帧、镜头设计、灯光设计和连续性计划编译成可直接用于图生视频软件的导演级Prompt。

视频Prompt不能只是动作摘要。它必须同时控制：

- 从什么画面开始；
- 最终必须抵达什么画面；
- 人物、道具和环境在时间轴中如何变化；
- 摄影机从哪里开始、何时运动、移动多远、在哪里停止；
- 光从哪里来、以什么色温和软硬度照亮什么区域；
- 焦点、景深、曝光、高光和暗部如何保持；
- 哪些内容允许运动，哪些内容必须绝对稳定；
- 当前镜头如何为下一镜提供准确的连续性尾态。

## 视频Prompt完整公式

```text
输入帧与生成模式
+ 视频类型与时长
+ 场景空间和前中后景
+ 主体人物与起始状态
+ 时间轴动作节拍
+ 动作物理、接触和重心
+ 摄影机参数与运动时间轴
+ 焦点、景深和曝光
+ 逐镜灯光合同
+ 色彩与材质
+ 环境动态
+ 结束帧合同
+ 下一镜连续性
+ 声音
+ 稳定项
+ 负面约束
```

禁止将“电影感、真实光照、缓慢推进”当成完整描述。

## 一、先决定生成模式

### A. 单首帧图生视频

只有同时满足以下条件时才能使用：

1. 主要动作是呼吸、眨眼、轻微抬手、布料微动、雨水、水波等低幅度运动；
2. 道具不发生关键状态变化；
3. 人物姿势、手部位置和视线终点不需要被下一镜精确继承；
4. 摄影机固定或运动幅度极小；
5. 结尾允许从生成结果中选择稳定尾帧；
6. 下一镜为独立硬切，或可以使用抽取尾帧继续。

单首帧不等于不控制结尾。必须同时编写完整的`END_FRAME_CONTRACT`，生成后抽取满足合同的稳定尾帧。

### B. 首尾帧视频

出现以下任一情况时默认使用首尾帧：

- 下一镜需要继承人物准确姿势、视线、手部、道具位置或屏幕方向；
- 人物外貌、服装、情绪可见状态、面部状态发生变化；
- 道具被拿起、放下、打开、关闭、翻转、破坏、清理或移动到固定位置；
- 镜头运动改变最终构图、景别或焦点；
- 人物必须最终停在一个明确表演姿态；
- 动作终点承担叙事信息；
- 单首帧容易产生随机尾态或与下一镜不连续。

首尾帧不是额外角色资产，而是当前镜头的起终控制帧。

### C. 抽尾帧续拍

当一段动作需要分成两段连续视频时：

1. 第一段生成后抽取最后一个身份、手部、道具、背景和光线稳定的帧；
2. 将其作为下一段唯一首帧；
3. 下一段只继续尚未完成的动作；
4. 不重新设计人物、场景和构图。

### D. 两段生成后硬切

出现以下情况时，不强迫单次模型连续生成：

- 构图或机位变化较大；
- 同时存在人物状态变化、道具变化和特效变化；
- 遮挡前后需要切换稳定状态；
- 多人交互或精确手部持续失败；
- 首尾帧之间需要不自然的变形才能连接。

分别生成两段，再在动作节点、遮挡、声音或视线处硬切。

### E. 分层合成

镜面人物、倒影、雾气、火花、粒子、屏幕内容、精确文字和复杂状态变化，优先拆为底板、主体层、效果层和遮罩层。不要让一个视频模型同时承担全部图层。

## 二、结束帧合同

每一个镜头都必须设计结束帧，即使没有预先生成尾帧。

```yaml
end_frame_contract:
  exact_time:
  character_pose:
  face_and_gaze:
  hands_and_contact:
  prop_position_and_state:
  camera_position_and_framing:
  focus_target:
  foreground_midground_background:
  lighting_state:
  allowed_residual_motion:
  stable_hold_frames:
  next_shot_inheritance:
```

要求：

- 结束状态必须可见、可截图、可验证；
- 明确人物手脚、道具和视线位置；
- 明确镜头终点和焦点终点；
- 结尾至少稳定停留12至24帧，除非明确要在运动中切断；
- 下一镜依赖该尾态时，必须预制尾帧或抽取稳定尾帧，不能让模型自由结束。

## 三、时间轴动作编译

动作必须按镜头时长写成可执行时间段。示例：

```text
0.0—0.8秒：保持首帧姿势，只有呼吸和衣料微动；
0.8—3.4秒：右手以匀速移动8厘米，手腕保持水平；
3.4—4.2秒：道具落入支架，产生一次轻微承重震动；
4.2—5.0秒：双手松开并停住，保持尾帧不少于0.5秒。
```

### 起始状态

写清：

- 身体姿态；
- 头部朝向；
- 视线落点；
- 左右手位置；
- 道具接触点；
- 重心和脚部；
- 当前呼吸和停顿。

### 起势

写清动作前的微小准备：视线、呼吸、手指收紧、重心转移或肩部发力。普通动作不需要夸张蓄力。

### 过程

按时间顺序写1至3个动作节点，量化方向、距离、角度、速度和接触。

### 收住

写清最终姿态、手的位置、道具状态、视线、呼吸和稳定停留。不能在动作中间随机结束。

## 四、动作物理

- 重物明确重量感、双手分工、肩臂受力和重心；
- 手与道具写明接触点、握持位置和移动路径；
- 脚部真实接地，禁止滑行和漂浮；
- 布料、头发和饰物只产生由动作或环境引起的合理运动；
- 动作速度使用“匀速、缓入缓出、先慢后停”等具体节奏；
- 动作幅度尽量量化为厘米、角度或画面比例。

## 五、摄影机合同

每镜必须写明：

```yaml
camera_contract:
  lens_or_equivalent:
  camera_height:
  camera_distance:
  shot_size:
  angle:
  axis_and_screen_direction:
  start_position:
  movement_type:
  movement_start_time:
  movement_end_time:
  direction:
  speed_curve:
  amplitude:
  endpoint:
  movement_motivation:
  stabilization:
```

要求：

- 固定镜头也要写“摄影机锁定，无平移、摇镜、旋转和数字变焦”；
- 推进、横移和升降尽量量化，例如推进画面宽度5%、横移40厘米、环绕12度；
- 写明运动在第几秒开始和结束；
- 一个短镜头只使用一种主要运镜；
- 运镜必须服务揭示、压迫、空间确认、动作跟随或情绪距离；
- 没有叙事理由时使用固定镜头。

## 六、焦点、景深和曝光合同

每镜必须写明：

```yaml
optical_contract:
  depth_of_field:
  focus_at_start:
  focus_transition:
  focus_at_end:
  lens_breathing:
  exposure:
  white_balance:
  highlight_protection:
  shadow_detail:
  motion_blur:
```

要求：

- 焦点必须落在具体对象，例如近侧眼睛、刀尖、镜面清洁区、纸张栏目；
- 发生焦点转移时写清起点、终点、开始和结束时间；
- 不用“浅景深”掩盖身份和手部错误；
- 曝光写明正常、略欠曝或高光保护；
- 高光不能掩盖镜面、皮肤和关键道具；
- 暗部必须保留空间和材质层次；
- 镜头呼吸只能轻微自然。

## 七、逐镜灯光合同

每条最终视频Prompt都必须包含当前镜头具体灯光，不能只引用全局视觉圣经。

```yaml
lighting_contract:
  key_source:
  key_direction:
  key_height:
  key_softness:
  key_color_temperature:
  key_intensity:
  fill_source:
  fill_intensity:
  practical_lights:
  rim_or_separation_light:
  background_light:
  lighting_ratio:
  illuminated_areas:
  shadow_areas:
  shadow_direction:
  highlight_control:
  atmospheric_light:
  continuity_with_previous_and_next:
  forbidden_light_changes:
```

最低要求：

1. 写清主光是什么真实光源；
2. 写清来自画面哪一侧、人物前后关系和大致高度；
3. 写清冷暖或具体开尔文数值；
4. 写清光线软硬和强弱；
5. 写清照亮人物或道具的哪些区域；
6. 写清哪一侧保持阴影以及阴影不能死黑；
7. 写清辅光、实景灯和背景光；
8. 写清大致光比，例如1:2、1:4；
9. 写清高光和暗部策略；
10. 写清整段视频中光源位置、方向、色温和曝光不得闪烁或漂移。

示例：

```text
主光是画面左侧木格窗外的5600K阴天漫射光，从人物左前上方约35度进入，
形成柔和但方向明确的窗口侧光，照亮左侧额头、手背、铜镜左缘和工作台纹理；
人物右侧脸和作坊后部保持约1:4的自然阴影，暗部仍能辨认皮肤、旧木和工具轮廓。
工作台油灯为约2800K极弱实景光，只在刀柄和铜粉上形成小面积暖色高光，不照亮整张脸。
整个镜头中窗光方向、鼻影方向、镜面高光和油灯亮度固定，不闪烁、不改变色温。
```

## 八、画面空间与材质

最终Prompt必须形成明确画面，而不是只列动作：

- 前景是什么，是否遮挡；
- 中景主体位于画面哪个区域；
- 背景地标和空间纵深；
- 构图重心、留白和视线方向；
- 皮肤、布料、木材、金属、纸张、水面等关键材质；
- 空气中雨雾、尘埃、烟和体积光的范围与强度；
- 哪些固定元素完全不动。

## 九、光线和颜色连续性

必须继承同一场景的：

- 主光来源和屏幕方向；
- 主光色温；
- 阴影方向；
- 白平衡；
- 光比和曝光倾向；
- 镜面及道具高光位置；
- 主色、辅助色和点缀色；
- 黑位和高光策略。

时间变化必须在剧本中有依据，并写清变化幅度。禁止模型自行变亮、变暗、闪烁、偏黄、偏蓝或增加无来源轮廓光。

## 十、声音字段

按工具能力写环境音、呼吸、衣料、道具接触、台词、音乐和沉默。不支持原生声音时明确转入后期，不假装视频模型一定生成。

## 十一、最终Prompt写作标准

最终可复制Prompt必须是完整、具体、具有画面顺序的自然语言，不得只输出字段清单。

每镜至少写清：

- 输入模式与首尾帧；
- 画面空间和构图；
- 起始姿态；
- 分秒动作过程；
- 动作物理；
- 摄影机参数和运动终点；
- 焦点、景深和曝光；
- 逐镜灯光；
- 材质和环境动态；
- 精确尾帧；
- 下一镜继承；
- 声音和负面约束。

不得为了“方便复制”压缩成几句通用话。

## 十二、输出格式

每镜使用`templates/video-shot-prompt-block.md`。完整正向Prompt、负面Prompt、输出规则、尾帧控制、衔接和失败修复必须位于同一镜头块。

## 视频Prompt硬失败

以下任一情况直接判定FAIL：

- 只写动作和运镜，没有画面、光线、焦点和尾帧；
- 使用单首帧，但下一镜依赖精确尾态且未提供尾帧或抽尾帧方案；
- 每镜没有结束帧合同；
- 只写“真实光照、电影感、冷色调”；
- 未写主光来源、方向、照亮区域和暗部；
- 光源方向和色温在同一镜头或相邻镜头中漂移；
- 未写景深和焦点；
- 运镜没有开始时间、结束时间、方向、幅度和终点；
- 一个五秒镜头包含过多动作与运镜；
- 没有可见的结尾状态或稳定停留；
- 视频Prompt重新设计人物、服装或场景；
- 首尾帧构图差异过大却强迫平滑变换；
- 声音要求与工具能力不匹配且未转入后期。
