# Storyboard Frame Prompt System

## 目标

把S09确认的镜头表编译为S10完整分镜帧Prompt包。静态帧负责锁定准确瞬间，视频负责运动。

## 前置条件

- 剧本已确认；
- 视觉圣经已建立；
- 用户已确认资产；
- 镜头表已完成；
- 每镜有唯一主要目的。

## 分镜帧输入

每镜引用：

```yaml
frame_input:
  character_identity:
  costume_state:
  environment_plate:
  environment_angle_or_layout:
  prop_state:
  pose_or_interaction_reference:
  color_reference:
  previous_shot_output_state:
```

## 首帧设计

首帧必须说明：

- 人物和道具准确位置；
- 动作起始姿态；
- 重心、朝向和视线；
- 前中后景；
- 景别和机位；
- 动作运动空间；
- 光线和场景状态；
- 上一镜继承内容。

首帧不要预先完成本镜头的主要动作。

## 尾帧设计

以下镜头必须或优先制作尾帧：

- 人物外观、服装或情绪可见状态变化；
- 道具打开、破裂、燃烧、变形或消失；
- 建筑或环境状态改变；
- 指定动作终点很重要；
- 下一个镜头需要从该姿态续拍；
- 单首帧视频常无法抵达准确终点。

尾帧必须说明：动作完成程度、人物和道具最终位置、摄影机终点、焦点终点和下一镜继承状态。

## 图片Prompt公式

调用`image-prompt-compiler.md`：

```text
已批准资产引用
+ 当前静态瞬间
+ 场景空间
+ 服装道具和接触
+ 景别机位构图
+ 光线色调材质
+ 连续性锚点
+ 输出规则
+ 负面约束
```

## 同一场景下一镜一致性

使用上一张分镜作为色调与空间参考时：

- 参考其色调、光线方向、对比度和质感；
- 不复制构图和动作；
- 同一角色和场景使用原资产参考；
- 新镜头只改变摄影机和当前动作瞬间；
- 背景地标必须出现在正确方向。

## 硬切新首帧

硬切允许改变景别和机位，但必须继承：

- 人物身份；
- 发型和服装状态；
- 道具状态、持手和朝向；
- 动作进度；
- 人物站位关系；
- 场景布局；
- 光线方向；
- 色调；
- 前一镜可见事实。

新首帧要为下一动作留出空间。

## 多人站位

复杂多人场景先锁定导演台或布局图：人物位置、朝向、比例、姿态和摄影机。换机位时人物不动，只移动摄影机。

全景或中远景优先用于空间锚定。过早使用极近特写会增加多角度穿帮风险。

## 九宫格使用边界

### 可用

- 连续打斗；
- 舞蹈；
- 复杂仪式；
- 物理特效；
- 多阶段动作；
- 多机位预演。

### 不应机械使用

- 普通对话；
- 静态环境；
- 简单拿起、转头、坐下；
- 已经有清楚单镜设计的段落。

九宫格是预演资产，不默认作为正式分镜图。

## 每镜完整输出

使用`templates/storyboard-frame-prompt-block.md`，包含：

- 镜头ID和功能；
- 时间和时长；
- 参考资产；
- 继承状态；
- 首帧设计；
- 首帧正向Prompt；
- 首帧负面Prompt；
- 首帧输出规则；
- 尾帧设计与Prompt（需要时）；
- 图生图修改Prompt；
- 局部修复Prompt；
- 视频动作摘要；
- 连续性锚点；
- 稳定替代。

## 输出批次

S10默认一次性交付全部镜头。内容过长时可按镜头区间分多个写作块，但必须同一轮完整交付，不逐镜等待用户确认。

## 分镜帧硬失败

- 每镜重新描述并改造角色身份；
- 首帧已经包含动作终点；
- 尾帧改变身份、场景布局或光线方向；
- 静态Prompt描述完整时间过程；
- 多人站位在换机位时漂移；
- 硬切新图与上镜动作进度不连续；
- 镜头没有输出规则或负面约束；
- 每张图色调由模型自由决定。
