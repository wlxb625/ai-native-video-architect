# Image Prompt Compiler V4.5 Extension

## 作用

本文件是`image-prompt-compiler.md`的增量扩展。原编译器的图片类型、参考职责、主体身份、静态瞬间、构图、表演、灯光、材质、正负Prompt和输出规则全部保留。本扩展只增加场景功能、视觉密度、动作语义、焦点统一、原创结构、材质漂移和画幅适配的编译要求。

## 必读依赖

编译剧情帧、概念图、氛围图、START / END / BRIDGE CF前读取：

- `references/scene-function-taxonomy.md`；
- `controllers/scene-function-router.md`；
- `controllers/frame-clarity-density-controller.md`；
- `templates/scene-function-frame-control-block.md`。

## 扩展编译公式

在原基础公式中加入：

```text
主场景功能与观众第一/第二/最终阅读
+ 信息、情绪、奇观优先级
+ 核心大形、中尺度结构和细节集中区
+ 主体清洁区、视觉休息区与细节衰减
+ 主要流动元素、辅助元素、微粒和颗粒策略
+ 叙事动作阶段、接触、重量、方向和可见结果
+ 关系残留与非自愿情绪泄漏（适用时）
+ 焦点、最亮区、最高对比区、色彩锚点与世界变化起点
+ 缩略图可读性
+ 项目专属原创结构与常见模板反制
+ 材质可观察属性与语义漂移反制
+ 当前画幅下重建后的主体占比、负空间和动势
```

## 编译顺序补充

### 1. 先路由场景功能

不能先写华丽、现实主义、电影感等风格词。先确定本帧主要负责叙事、震撼、共鸣、氛围、隐喻、反转、释放、治愈、悬疑或抽象中的哪一项，再决定信息密度和观看重点。

### 2. 定义第一视觉关系

用一句话写清第一眼成立的关系，例如：

- 巨大倾斜结构压向正在完成动作的小人物；
- 冷暖门框两侧的两个人刚刚松开同一个物件；
- 狭长走廊尽头唯一亮区中出现不应存在的背影。

若一句话包含过多并列元素，优先删减或拆镜。

### 3. 编译视觉层级

明确：

- 1—4个核心大形；
- 承担结构、秩序和叙事的中形；
- 只在重点区域出现的小形；
- 主体清洁区；
- 视觉休息区；
- 前中远景锐度、纹理、对比和装饰衰减。

“超高细节”不得单独出现，必须说明细节集中在哪里、哪里简化。

### 4. 编译动作阶段

图片只能冻结一个阶段。必须说明动作属于：

- 准备；
- 刚接触；
- 正在发生；
- 刚完成；
- 完成后的残留。

写清接触是否存在、重量由谁承担、手掌和手指方向、手腕与肘部趋势、身体重心以及结果状态。针对最可能误读加入正向反制，不只依赖负面词。

### 5. 编译关系残留

情绪关系镜头直接写入：

- 接触刚刚如何结束；
- 当前距离；
- 手指、视线、嘴唇、呼吸或道具如何保留余温；
- 至少一个非自愿情绪泄漏；
- 道具如何显示重量转移和生活历史。

不得用哭泣、拥抱和抽象悲伤替代。

### 6. 对齐焦点

叙事动作区、局部最亮区、最高局部对比、唯一或主要高饱和色、最高锐度和世界变化起点默认需要共同指向同一重点。故意错开时必须说明观众误判或揭示理由。

### 7. 控制华丽与噪声

华丽项目在正向Prompt中写：

- 华丽来自何种空间尺度；
- 中尺度结构如何形成秩序；
- 哪些材质互相对照；
- 哪一处装饰最密，哪几处保持干净；
- 主要流动元素和微粒上限。

禁止将“极致华丽”自动编译成满屏金粉、花瓣、羽毛、珠链、裂纹和光点。

### 8. 建立原创替代结构

避免常见模板不能只写“不要”。正向Prompt必须定义：

- 大形是什么；
- 如何连接、受力或生长；
- 重复结构如何变化；
- 与人物行动有什么因果；
- 为什么不等于常见莲花、光环、仙山、传送门、帆片或工业装置。

### 9. 反制材质漂移

每个重要材质写：

- 哑光或反射粗糙度；
- 半透、透明或不透明程度；
- 重量与厚度；
- 边缘与受力方式；
- 真实光照响应；
- 重力、折痕、磨损和使用痕迹；
- 常见错误替代物。

### 10. 画幅重建

比例改变时重新编译：

- 人物占比；
- 视线空间；
- 负空间功能；
- 主动势；
- 大形是否超框；
- 手机或宽银幕观看距离；
- 不可裁切区。

不能只替换“16:9 / 9:16”文字。输出规则必须提醒外部平台设置实际比例参数。

## 正向Prompt强制覆盖

剧情型最终正向Prompt除原字段外必须直接包含：

1. 主场景功能产生的第一视觉关系；
2. 一个准确动作阶段和防误读结果；
3. 核心大形、中形、细节集中区、清洁区和休息区；
4. 焦点与光色对齐；
5. 主要流动元素、微粒和颗粒控制；
6. 关系残留或环境节奏；
7. 原创结构和材质语义反制；
8. 当前画幅下的构图重建；
9. 针对性负面约束。

## 负面Prompt补充

负面Prompt必须针对当前帧，优先覆盖：

- 动作相反语义；
- 接触、重量和手部错误；
- 主体清洁区污染；
- 密集粒子和高频纹理；
- 商品广告、公益宣传、角色海报或摆拍风险；
- 常见视觉模板；
- 材质替代物；
- 焦点和光色错位；
- 比例、裁切和平台输出风险。

禁止机械复制万能负面词。

## 单张实测后的处理

真实生成图用于验证系统规则，而不是无限围绕同一张图局部改写。审核时先区分：

- Prompt系统性缺口；
- 当前视觉方案问题；
- 平台参数问题；
- 模型能力或随机误差；
- 适合局部修复的问题。

若用户要求完善整个Skill，应先收束跨场景共性规则并完成整体整合，再进行新一轮横向测试；不得把用户拖入同一图片的无限微调。
