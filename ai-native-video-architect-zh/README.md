# AI Native Film Studio V4.2

一套覆盖 **故事、剧本、生图、分镜、生视频、生产验收和后期交付** 的中文AI视频创作Skill。

```text
$ai-native-video-architect-zh
```

它不是只写Prompt的工具。用户可以从模糊想法、已有剧本、歌曲与歌词、参考图、分镜、视频Prompt或实际生成片段中的任意位置进入，Skill会识别已经完成的内容，只继续处理当前缺失的部分。

## 适合的项目

- AI短片、微电影和剧情短视频；
- 无对白视觉叙事；
- 悬疑、恐怖、科幻、现实主义、喜剧和实验影像；
- 高概念短片、精品MV、视觉单曲和艺人概念片；
- 时尚影像、舞蹈与表演影像；
- 广告、品牌故事和品牌情绪片；
- 小说、文章、大纲或现有剧本的视频化改编；
- 已有参考图、分镜或生成片段的继续制作与修复。

## 精品MV与视觉作品方向

V3中较强的视觉叙事、视觉母题、声画关系、意识流和形式规则能力在V4.2中继续保留。它不仅可以服务剧情短片，也适合发展为精品MV与高完成度视觉作品生产方案。

可以从以下材料开始：

- 一首完整歌曲或Demo；
- 歌词、主题、情绪或音乐风格；
- 艺人形象、造型和视觉参考；
- 舞蹈、表演或口型需求；
- 一个核心场景、物件或视觉概念；
- 已经存在的MV方案、分镜或生成片段。

可以完成：

- 分析前奏、主歌、副歌、桥段和尾奏的情绪与视觉职责；
- 建立核心视觉概念、视觉母题和重复变义规则；
- 设计艺人表演、口型、舞蹈、走位与镜头关系；
- 规划场景、造型、道具和人物状态变化；
- 设计主视觉镜头、记忆点镜头、封面画面和宣传切片；
- 建立节拍切点、歌词对应、旋律推进、声音桥和主动留白；
- 设计色彩、灯光、材质和剪辑节奏的整片变化曲线；
- 同时考虑横版MV、竖版短视频、预告和封面素材；
- 继续完成参考图、分镜、首尾帧、视频Prompt、样片验证和实际生产。

精品MV不一定需要传统剧情。它也可以依靠音乐结构、表演关系、视觉母题、空间变化和情绪递进形成完整观看体验，但不能只是互不相关的漂亮画面拼接。

# 核心功能

## 1. 创意、故事与剧本

### 从想法发展成故事

可以从题材、人物、情绪、关系、核心物件或一个视觉画面开始，补齐真正影响创作的条件，包括目标时长、画幅、平台、叙事形式、声音方向和禁忌。

方向不明确时，可以提供两到三个真正不同的创意方案，并比较：

- 主角或主体；
- 可观察任务；
- 核心事件、机制或形式规则；
- 人物关系与私人代价；
- 视觉身份；
- 高潮由谁选择和行动；
- 结尾方向；
- 制作风险。

### 故事方案

可以完成：

- 一句话概念；
- 观众持续关心的问题；
- 人物目标、阻碍和关系；
- 核心机制及其代价与限制；
- 开场偏差、中段变化和递进；
- 无法两全的关键选择；
- 高潮的选择者、行动者和代价承担者；
- 结局事实、开放事实和最后图像。

高概念项目会压缩为少量真正有效的机制，避免把长片信息量塞进短片，也不会为了制造反转机械添加“主角其实是AI、死人或复制体”。

### 正式剧本与视觉脚本

剧情剧本可以包含：

- 场次、地点、时间和现实层级；
- 可观看的动作、空间和道具状态；
- 人物动作与表演；
- 对白、旁白、录音和画面文字；
- 环境声、动作声和音乐关系；
- 场景退出状态与下一场继承；
- 高风险动作、口型和后期提示。

无对白、MV、广告、意识流和实验项目会建立完整视觉脚本，明确主体初始状态、可观察动作、环境与道具变化、情绪或关系变化、最终状态和场景连接，而不是只输出一组互不相关的意象。

### 视觉叙事

支持通过人物行动、空间痕迹、物件状态、重复动作、声音母题和前后画面变化，让观众推断关系与历史。视觉母题需要改变含义，而不是只重复出现或更换颜色。

### 对白、旁白和声音

不会为了“视觉化”机械删除所有对白。对白可继续承担请求、拒绝、试探、欺骗、关系压力、信息差和高潮选择。

解释性旁白或字幕可以转化为人物动作、物件位置、空间痕迹、重复动作变化、声音反差或结果镜头。声音设计可以包括世界声、人物声、动作声、声音母题、音乐曲线和主动沉默。

### 诊断与改写

可以诊断故事、剧本、分镜、Prompt或生成片段，并区分：

- `BUG`：明确错误；
- `RISK`：当前可用但存在风险；
- `CHOICE`：作者有意设计，应当保护；
- `OPPORTUNITY`：可选增强；
- `PREFERENCE`：审美或市场偏好。

修改已有作品时，可选择从校对、轻优化、结构优化、方向增强到深度改编的不同等级。未经授权不会随意改变人物关系、关键选择、高潮主体、结尾和开放程度。

## 2. 视觉设定与生图Prompt

### 视觉规则

可以建立：

- 画幅与视觉风格；
- 主色、辅色、强调色和色温；
- 饱和度、对比度和曝光倾向；
- 真实光源及其世界空间方向；
- 皮肤、布料、木材、金属、纸张等材质规则；
- 摄影倾向和禁止出现的视觉效果。

### 最小参考原则

普通短片和MV优先使用最少但够用的参考图：

- 每名主要角色或艺人先判断一张独立身份主参考是否足够；
- 每个主要场景通常先建立一张无人物空镜；
- 核心道具只在跨镜头必须稳定时单独建立参考；
- 特殊造型和状态只在作品需要精确控制时单独制作；
- 全身、面部、手部、三视图、综合角色板和第二机位按实际镜头或真实失败增加。

不默认密集六宫格，也不机械规定每名角色必须生成多张参考。

### 资产Prompt

可输出：

- 角色或艺人身份、服装、妆发、面部和手部参考；
- 场景空镜和必要第二角度；
- 核心道具结构与状态参考；
- 特殊造型和状态参考；
- 首帧、尾帧、控制帧和局部修复Prompt。

每条最终正向Prompt会自然融合：

```text
主体身份和用途
+ 构图与主体位置
+ 摄影机、焦段、机位、焦点和景深
+ 曝光、白平衡、高光和暗部
+ 主光来源、方向、色温、软硬、亮区和阴影
+ 皮肤、布料、木材、金属等材质
+ 背景、空间与连续性要求
```

用户不需要自行拼接人物描述、摄影合同和灯光合同。

## 3. 镜头表、分镜与控制帧

可以一次性完成整片镜头设计。每个镜头会明确：

- 镜头目的和主要信息；
- 输入状态和静态起点；
- 人物、双手、道具与空间位置；
- 景别、焦段、机位、轴线和屏幕方向；
- 前景、中景、背景与构图；
- 摄影机运动及其动机；
- 焦点、景深、曝光和逐镜灯光；
- 时长、音乐段落、声音和剪辑连接；
- 精确结束状态与下一镜继承；
- 高风险点和稳定替代方案。

静态分镜Prompt只描述一个准确瞬间，可用于：

- 镜头首帧；
- 必要尾帧；
- 动作中间控制帧；
- 遮挡切换桥接帧；
- 镜面、倒影和状态变化控制；
- 下一段视频的续拍起点。

每镜都会建立结束帧合同。下一镜依赖准确姿势、视线、手部、道具、焦点或构图时，优先预制尾帧或抽取稳定尾帧。

## 4. 导演级视频Prompt

根据镜头需要选择：

- `SINGLE_START_FRAME`：单首帧低幅度运动；
- `FIRST_LAST_FRAME`：首尾帧控制；
- `TAIL_FRAME_CONTINUATION`：抽取尾帧续拍；
- `TWO_SEGMENT_HARD_CUT`：两段生成后硬切；
- `OCCLUSION_SWITCH`：利用遮挡切换状态；
- `LAYERED_COMPOSITE`：分层生成与后期合成。

每镜视频Prompt可以包含：

- 输入参考和生成模式；
- 场景空间、构图和主体起始状态；
- 按秒划分的动作时间轴；
- 动作距离、角度、速度、重量与接触；
- 焦段、机位、轴线和摄影机运动；
- 焦点、景深、曝光和白平衡；
- 当前镜头的真实光源、方向、色温和光比；
- 材质和环境动态；
- 精确结束帧和稳定停留；
- 下一镜继承；
- 音乐、声音和负面约束。

镜面人物、倒影、薄雾、精确文字、复杂手部、口型、舞蹈和多状态变化不会被强迫一次生成，可以拆段、遮挡或分层完成。

## 5. 实际生产、验收与修复

Prompt完成后仍可继续组织真实生产：

- 从候选图中选定唯一角色、艺人、场景、道具和状态母参考；
- 先测试一个普通正片镜头和必要的高风险镜头；
- 建立控制帧依赖和镜头生成顺序；
- 管理每镜候选版本、Prompt版本和文件命名；
- 检查换脸、服装漂移、场景重建、道具变形、手部错误和灯光闪烁；
- 检查摄影机、焦点、动作物理、尾帧可达性和可剪辑性；
- 检查MV镜头与节拍、歌词、表演和整体情绪曲线是否一致；
- 判断问题应重做参考图、修复控制帧、调整Prompt、改变生成模式还是转入后期。

失败可以区分为：

- `REFERENCE_FAILURE`；
- `CONTROL_FRAME_FAILURE`；
- `PROMPT_FAILURE`；
- `MODEL_CAPABILITY_FAILURE`；
- `POST_PRODUCTION_FAILURE`。

修复优先处理真正薄弱的层级，不因一个局部问题重做整个项目，也不会用无限增加资产解决模型能力问题。

## 6. 剪辑与后期

可以继续规划：

- 镜头版本选择、排序、入点和出点；
- 动作匹配、视线匹配和声音桥；
- 节拍切点、歌词对应、音乐段落和情绪曲线；
- 硬切、遮挡切换、续拍和分层合成；
- 精确文字、字幕和图形；
- 镜面、倒影、雾气和遮罩；
- 环境声、动作声、音乐和沉默；
- 全片曝光、色彩、灯光和颗粒统一；
- 横版、竖版、预告、封面和最终导出规格。

只有通过实际验收的镜头版本才进入最终时间线。

# 主要输出

根据用户当前材料，可以直接输出：

- 创意方向和故事方案；
- 完整剧情剧本、视觉脚本或MV视觉方案；
- 歌曲结构、视觉母题、表演与声画节奏设计；
- 作品诊断、保护合同和改写稿；
- 视觉设定与最小参考计划；
- 角色、艺人、场景、道具和状态Prompt；
- 镜头表与摄影设计；
- 首帧、尾帧和控制帧Prompt；
- 导演级视频Prompt；
- 代表性样片方案；
- 生产运行手册和镜头台账；
- 实际镜头验收与最小修复方案；
- 剪辑、声音、调色和最终交付方案。

# 使用示例

## 从想法开始

```text
使用 $ai-native-video-architect-zh，
我想做一部60秒无对白悬疑短片，
先帮我确定故事，再继续完成剧本和视觉制作。
```

## 制作精品MV

```text
使用 $ai-native-video-architect-zh，
这是歌曲、歌词和艺人视觉参考，
请先完成音乐结构与视觉概念分析，
再设计视觉母题、表演、场景、分镜和视频Prompt。
```

## 使用已有剧本

```text
使用 $ai-native-video-architect-zh，
这是已经确认的剧本，不修改人物关系、高潮和结尾，
直接进入视觉设定、核心参考图和分镜设计。
```

## 使用已有图片

```text
使用 $ai-native-video-architect-zh，
这些是已经选定的角色图和场景图，
帮我完成镜头表、首尾帧和视频Prompt。
```

## 修复生成片段

```text
使用 $ai-native-video-architect-zh，
检查这段视频为什么出现换脸、手部错误和尾帧失败，
并给出最小重做方案。
```
