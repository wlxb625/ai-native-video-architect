# AI Native Film Studio V4.2

一个面向AI短片、剧情视频、视觉实验和商业内容的中文创作Skill。

它可以从一个模糊想法开始，逐步完成故事、剧本、角色与场景参考图Prompt、分镜、首尾帧、导演级视频Prompt，并继续组织实际生成、镜头验收、剪辑和后期交付。

用户不需要在剧本、生图和视频阶段之间切换不同的Skill。

## 调用方式

```text
$ai-native-video-architect-zh
```

也可以直接描述当前需求，例如：

```text
我有一个60秒悬疑短片想法，帮我完成故事和剧本。
```

```text
这是我的完整剧本，直接帮我设计角色、场景和分镜。
```

```text
我已经有角色图和场景图，帮我生成首尾帧Prompt和视频Prompt。
```

```text
这个生成片段出现了换脸和灯光漂移，帮我判断问题并修复。
```

## 适合的创作类型

- AI短片与微电影；
- 剧情短视频；
- 悬疑、现实主义、科幻、恐怖与实验影像；
- 品牌故事和商业视觉内容；
- 无对白视觉叙事；
- 小说、文章或现有剧本的视频化改编；
- 已有图片、分镜或生成片段的继续制作。

## 可以从任何阶段开始

Skill会先判断用户已经拥有什么，再从当前真正缺失的环节继续。

支持的入口包括：

- 一个想法、题材或情绪；
- 人物设定或故事梗概；
- 已完成的大纲或剧本；
- 角色图、场景图和道具图；
- 镜头表或分镜图；
- 首帧、尾帧和控制帧；
- 已编写的视频Prompt；
- 已生成但存在问题的视频片段；
- 已进入剪辑阶段的项目。

## 完整功能

### 1. 创意与故事设计

- 提炼一句话核心概念；
- 建立主角任务、人物关系和世界规则；
- 设计递进、选择、高潮和结尾；
- 根据目标时长控制故事密度；
- 选择商业、文学、实验或混合创作路径；
- 检查故事是否适合通过画面表达。

### 2. 剧本创作与改编

- 从想法生成完整剧本；
- 将故事梗概扩展成可制作脚本；
- 将小说、文章或现有内容改编为视频剧本；
- 设计场次、动作、对白、声音和视觉信息；
- 保护原作中的人物目标、关键选择、高潮和结尾；
- 根据AI生成能力调整实现方式，而不随意改变故事核心。

### 3. 视觉设定

- 确定画幅、时代、环境和整体视觉方向；
- 设计角色外形、服装和固定身份标记；
- 设计场景布局和空间地标；
- 设计核心道具及其状态变化；
- 统一色彩、曝光、材质和灯光规则；
- 建立全片连续性锚点。

### 4. 核心参考图Prompt

Skill默认使用最少必要参考，而不是为普通短片建立庞大资产库。

可生成：

- 角色身份主参考；
- 面部近景或全身服装参考；
- 角色与核心道具交互参考；
- 标准人物三视图或综合角色板；
- 无人物场景空镜；
- 核心道具结构图；
- 特殊状态参考图。

角色通常先判断一张身份主参考是否足够。只有镜头确实需要时，才增加全身、手部、多视图或特殊状态资产。

每条最终资产正向Prompt会完整包含：

```text
主体身份和用途
+ 构图与主体位置
+ 摄影机、焦段、机位、焦点和景深
+ 曝光、白平衡、高光和暗部
+ 主光来源、方向、色温、软硬和阴影
+ 皮肤、布料、木材、金属等材质
+ 背景和一致性要求
```

用户可以直接复制使用，不需要自行拼接摄影、灯光和人物描述。

### 5. 镜头表与分镜设计

每个镜头可以设计：

- 镜头任务和叙事信息；
- 景别、焦段和机位；
- 轴线和屏幕方向；
- 前景、中景和背景；
- 人物站位、视线、双手和道具关系；
- 摄影机运动；
- 焦点、景深和曝光；
- 当前镜头的具体灯光；
- 镜头时长和声音；
- 精确结束状态；
- 与下一镜的连接方式。

### 6. 首帧、尾帧与控制帧Prompt

静态分镜Prompt只描述一个准确瞬间，可用于：

- 镜头首帧；
- 镜头尾帧；
- 动作中间控制帧；
- 遮挡切换桥接帧；
- 镜面、倒影和特殊状态控制；
- 下一段视频的续拍起点。

后续分镜优先继承已经选定的角色、场景、道具和上一张满意控制帧，以减少换脸、场景重建和灯光漂移。

### 7. 导演级视频Prompt

视频Prompt不是简单的“人物缓慢移动、电影感”。

每个镜头会根据需要选择：

- 单首帧生成；
- 首尾帧生成；
- 抽取尾帧续拍；
- 两段硬切；
- 遮挡切换；
- 分层合成。

完整视频Prompt可以包含：

- 输入参考和生成模式；
- 画面构图和空间层次；
- 人物起始姿态和道具接触；
- 按秒划分的动作时间轴；
- 动作距离、角度、速度、重量和接触；
- 焦段、机位、轴线和摄影机运动；
- 焦点、景深、曝光和白平衡；
- 当前镜头的真实光源、方向、色温和光比；
- 材质与环境动态；
- 精确尾帧和稳定停留；
- 下一镜继承；
- 声音和负面约束。

镜面人物、倒影、薄雾、精确文字、复杂状态变化和高风险手部，可以拆成不同片段或图层完成，不强迫一个模型一次生成所有内容。

### 8. 实际生产组织

Prompt完成后，Skill还能继续组织实际生成流程，包括：

- 从候选图片中选定唯一角色、场景和道具母参考；
- 选择普通代表性镜头和高风险镜头进行样片测试；
- 建立控制帧依赖关系；
- 安排镜头生成顺序；
- 管理每个镜头的候选版本；
- 记录Prompt版本和生成结果；
- 判断是否需要重做参考图、控制帧、Prompt或生成方式；
- 规划硬切、续拍、遮挡和分层合成。

### 9. 生成结果验收与修复

可以根据真实图片或视频片段检查：

- 人物是否换脸；
- 服装和身份标记是否漂移；
- 场景布局是否变化；
- 道具结构和状态是否正确；
- 手部和接触关系是否可信；
- 摄影机是否执行了规定动作；
- 焦点、曝光和灯光是否稳定；
- 动作是否符合重量和物理；
- 尾帧是否准确抵达；
- 镜头是否能够与下一镜连接；
- 问题更适合重新生成还是留给后期。

修复时只处理真正薄弱的环节，避免因为单个问题重新制作整套项目。

### 10. 剪辑与后期方案

可继续规划：

- 镜头排序和节奏；
- 入点、出点和稳定尾帧；
- 动作匹配、视线匹配和声音桥；
- 硬切、遮挡切换和分层合成；
- 精确文字与字幕；
- 镜面、倒影、雾气和遮罩；
- 环境声、动作声和音乐；
- 全片曝光、色彩和颗粒统一；
- 最终导出和质量检查。

## 主要输出内容

根据项目阶段，可以输出：

- 创意简报；
- 故事方案；
- 完整剧本；
- 改编保护合同；
- 视觉设定；
- 最小参考资产计划；
- 角色、场景和道具Prompt；
- 镜头表和摄影设计；
- 首帧、尾帧和控制帧Prompt；
- 导演级视频Prompt；
- 代表性样片计划；
- 生产运行手册；
- 镜头验收报告；
- 剪辑与后期方案；
- 最终交付检查清单。

## 工作方式

Skill遵循以下原则：

- 用户已有的内容不重复询问；
- 已有完整剧本时直接进入下游制作；
- 故事、人物选择和结尾优先于技术便利；
- 普通项目使用最少必要参考；
- 最终Prompt可以直接复制；
- 每个镜头都有明确结束状态；
- 复杂变化可以分段、遮挡或分层完成；
- 生成失败时先判断问题所在层级；
- 只有通过验收的镜头版本进入最终时间线。

## 典型工作流程

```text
想法或已有内容
→ 故事与剧本
→ 视觉设定
→ 最小参考资产
→ 镜头表
→ 首帧、尾帧和控制帧
→ 导演级视频Prompt
→ 代表性样片
→ 批量镜头生成
→ 镜头验收与修复
→ 剪辑、声音和后期
→ 最终交付
```
