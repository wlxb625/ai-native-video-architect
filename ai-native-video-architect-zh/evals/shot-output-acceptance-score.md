# Shot Output Acceptance Score V4.4

## 用途

用于审核实际生成的图片或视频片段是否可以进入下一生产阶段。该评分器不能只根据Prompt评分；必须查看真实输出、关键帧或用户提供的生成结果。

未看到实际结果时，只能输出：

```yaml
status: PLAN_ONLY
reason: 尚无真实生成结果，不能判定样片或镜头通过。
```

## 总分

总分100分。

### 1. 首帧与尾帧忠实度｜18分

- 首帧未被擅自重绘；
- 动作起点符合控制帧；
- 结尾准确抵达`END_FRAME_CONTRACT`；
- 尾帧稳定保持规定时间；
- 下一镜依赖的姿态、视线、手部、道具、焦点和构图可直接继承。

### 2. 人物身份与服装连续性｜15分

- 面部身份、年龄、骨相和发型稳定；
- 服装结构、颜色、污渍、破损和配饰没有漂移；
- 特殊状态只在规定时间和区域发生；
- 没有随机美化、年轻化或换脸。

### 3. 场景、道具与手部交互｜12分

- 场景布局、固定地标和空间方向稳定；
- 核心道具尺寸、厚度、标记和状态正确；
- 左右手、手指数量、接触点和遮挡关系可信；
- 道具没有漂浮、穿模和无重量感。

### 4. 摄影机执行｜10分

- 焦段、机位、轴线和屏幕方向符合合同；
- 固定镜头没有额外运动；
- 运镜开始时间、方向、幅度、速度和终点正确；
- 没有意外数字变焦、旋转和画面漂移。

### 5. 焦点、景深与曝光｜10分

- 焦点落在规定主体；
- 拉焦时间和终点准确；
- 景深没有随机改变；
- 曝光、高光、暗部和白平衡稳定；
- 没有明显镜头呼吸或自动曝光泵动。

### 6. 灯光与色彩连续性｜12分

- 主光真实来源和世界空间方向正确；
- 人物受光区域和阴影方向连续；
- 色温、光比、实景灯和高光位置稳定；
- 没有闪烁、偏色、无来源轮廓光和突然变暖变亮；
- 相邻镜头可以调色统一。

### 7. 动作时间轴与物理｜10分

- 动作按规定时间发生；
- 距离、速度、角度和幅度可信；
- 重量、重心、惯性、接触和材料反应合理；
- 没有滑步、漂浮、关节反向和不必要二次动作；
- 短镜头只承担一个主要动作。

### 8. 可剪辑性与连接｜8分

- 入点和出点清楚；
- 结尾没有随机动作或突然变形；
- 可以通过既定硬切、动作匹配、视线匹配、声音桥或遮挡切换连接；
- 分段视频的桥接帧、灯光和动作百分比一致。

### 9. 后期可完成度｜5分

- 精确文字、雾气、镜面层和声音已经正确留给后期；
- 底板和分层素材干净；
- 没有把不可修复的生成错误推给后期；
- 裁切、跟踪、遮罩和调色具有可操作空间。

## 结果

- 90—100：`PASS`，可进入剪辑；
- 82—89：`PASS`，存在轻微可修问题；
- 70—81：`CONDITIONAL`，修复后重新验收；
- 低于70：`FAIL`，不能进入最终时间线。

## 硬失败

无论总分多少，以下任一情况直接`FAIL`：

- 关键人物换脸或身份无法确认；
- 核心道具结构、尺寸或剧情状态错误；
- 规定的结束帧没有抵达；
- 下一镜必须继承的手部、姿势、道具或构图不可用；
- 主光方向反转、曝光严重闪烁或色温突然跳变；
- 固定镜头出现明显无关运镜；
- 手指、肢体、接触和遮挡错误承担核心叙事信息；
- 遮挡切换未达到完整遮挡，导致状态变化穿帮；
- 分层镜头中人物、镜面、倒影或效果层相互穿透；
- 片段存在无法通过正常剪辑避开的严重变形；
- 没有真实生成结果却声称`PASS`。
