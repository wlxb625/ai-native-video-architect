# AI Native Film Studio V4.0

一套面向中文创作者的 **AI视频全流程导演与制作 Skill**。

它不只是生成剧本，也不只是编写单条 Prompt，而是把一个想法逐步推进为：

```text
创意方向 → 故事方案 → 完整剧本 → 视觉圣经
→ 角色 / 场景 / 道具资产 → 分镜设计
→ 分镜图 Prompt → 视频 Prompt → 后期与成片审查
```

显式调用：

```text
$ai-native-video-architect-zh
```

---

## 主要功能

### 1. 从想法发展为可制作剧本

可以从一句灵感、一个人物、一种情绪或已有故事开始，完成：

- 项目定位与创意方向；
- 世界观、人物和核心机制；
- 故事结构、节拍、高潮与结尾；
- 对白剧本、无对白视觉脚本或实验影像方案；
- 商业、文学、实验与混合创作路径；
- 已有剧本诊断、改写和制作适配。

它不会机械套用固定三幕结构，而是根据作品目标选择合适的叙事方式。

### 2. 将剧本转换为导演制作方案

剧本确认后，Skill会把文学内容转译为可以实际生成的生产信息，包括：

- 场景、人物、道具和时间线拆解；
- 视觉圣经与统一美术方向；
- 色彩、材质、光源、光线方向和暗部层次；
- 景别、机位、构图、焦段和镜头运动；
- 人物动作、环境变化和声音节奏；
- 高风险镜头识别与低风险替代方案。

### 3. 建立稳定的角色资产

为每个主要角色生成完整资产方案，而不是直接在分镜里反复“猜脸”：

- 面部身份板；
- 正面、侧面、背面三视图；
- 发型与服装结构板；
- 表情、手部和动作参考；
- 固定身份特征；
- 允许变化与禁止变化；
- 多人物身份区分测试；
- 人脸漂移和服装变化修复方案。

### 4. 建立场景与道具资产

在人物进入场景前，先锁定空间和重要物件：

- 场景主布局与俯视关系；
- 无人物空镜；
- 多机位和固定光源方向；
- 建筑、家具和材质细节；
- 道具正反面、尺寸、磨损和使用方式；
- 道具连续状态链；
- 场景与道具穿帮修复规则。

### 5. 输出可直接复制的生图 Prompt

每个资产和分镜图默认以独立完整块输出，包含：

- 用途和前置参考图；
- 必须保持与允许变化；
- 完整正向 Prompt；
- 针对性负面 Prompt；
- 构图、比例和输出规则；
- 稳定生成方案；
- 图生图与局部修改 Prompt；
- 文件命名和后续依赖。

图片 Prompt 遵循：

```text
主体 + 场景环境 + 静态动作瞬间 + 服饰道具
+ 景别 + 机位 + 构图 + 光线色调
+ 材质真实度 + 风格 + 比例 + 负面约束
```

一张图只负责一个准确瞬间，不让图片模型同时承担完整动作过程。

### 6. 设计完整分镜与分镜帧

在资产锁定后输出完整镜头表，包括：

- 镜头编号和时长；
- 景别、机位和焦段；
- 摄影机运动；
- 人物起始与结束状态；
- 环境变化；
- 调用的角色、场景和道具资产；
- 首帧、尾帧和硬切新首帧；
- 镜头之间的动作与视觉衔接；
- 声音、节奏和转场设计。

支持普通单帧、首尾帧、九宫格、多机位和多人站位控制。

### 7. 输出专业图生视频 Prompt

视频 Prompt 不只是“人物做什么”，还会同时控制：

- 唯一首帧和起始状态；
- 一个主要人物动作；
- 一种主要运镜；
- 环境中的自然微动；
- 光线、色调和时间变化；
- 动作速度与结束停点；
- 人物、服装、场景和道具稳定；
- 声音、对白和口型要求；
- 禁止出现的畸变与穿帮。

视频 Prompt 遵循：

```text
唯一首帧 + 视频类型 + 场景 + 主体 + 起始状态
+ 动作过程 + 运镜 + 光线色调 + 风格
+ 稳定要求 + 结尾 + 声音 + 负面约束
```

### 8. 内置运镜与镜头语言

支持并判断何时适合使用：

- 固定镜头；
- 推镜与拉镜；
- 横移与摇镜；
- 跟拍；
- 环绕；
- 升降；
- FPV运动；
- 焦点转移；
- 手持和长镜头；
- 硬切与抽尾帧续拍。

短镜头默认只保留一个主要动作和一种主要运镜，减少AI视频失控。

### 9. 连续性检查与失败修复

针对AI生图和AI视频常见问题，提供对应修复方案：

- 人脸和年龄漂移；
- 发型、服装和饰品变化；
- 手指与道具交互错误；
- 场景布局和光线方向变化；
- 多角度切换穿帮；
- 首尾帧无法衔接；
- 夜景噪点和塑料质感；
- 台词、口型和声音错误；
- 镜头动作过多或运镜失控；
- 图生图、局部重绘、降噪与清晰度增强。

### 10. 核心样片与成片交付

在批量制作前，先选择最能验证项目的高风险镜头制作核心样片，检查：

- 角色是否稳定；
- 视觉规则是否成立；
- 动作是否可生成；
- 镜中、反射、变形等复杂效果是否可控；
- 运镜和镜头衔接是否合理。

通过后再进入整片生产，并最终输出：

- 全片视频 Prompt；
- 镜头生成顺序；
- 声音与配乐方案；
- 剪辑与转场建议；
- 色调统一方案；
- 失败镜头回退方案；
- 导演审查和交付清单。

## 完整工作流

```text
S00 创作需求
→ S01 创意方向
→ S02 故事方案
→ S03 剧本或视觉脚本
→ S04 剧本拆解
→ S05 视觉圣经
→ S06 资产计划
→ S07 整批资产 Prompt 与资产制作
→ S08 用户自审与资产确认
→ S09 分镜设计
→ S10 整批分镜帧 Prompt
→ S11 核心样片
→ S12 整批视频生产与后期
→ S13 导演审查与交付
```

## 阶段交互方式

默认以“阶段”为单位推进，而不是每生成一张图片就中断：

- S07一次性给完全部资产 Prompt；
- S09一次性给出完整镜头设计；
- S10一次性给完全部分镜帧 Prompt；
- S11一次性给出核心样片测试包；
- S12一次性给出全片视频 Prompt 和后期方案；
- 用户默认在外部生图或视频工具中自行生成和筛选；
- 用户回复“下一步”，表示进入下一个阶段；
- 只有明确提出时，Skill才会逐图或逐镜头辅助审核。

## 适合哪些创作者

- 想使用AI制作短片、电影预告、短剧或MV的人；
- 有故事想法，但不熟悉导演、分镜和影视制作流程的人；
- 会使用生图或视频模型，但难以保持角色和场景一致的人；
- 希望把剧本、图片Prompt和视频Prompt放进同一个工作流的人；
- 想把现有剧本改造成更适合AI制作版本的创作者；
- 希望制作文学、悬疑、现实主义、意识流或实验影像的创作者。

## 使用示例

### 从零制作短片

```text
使用 $ai-native-video-architect-zh，
帮我设计一部60秒、无对白、东方志怪风格的AI短片，
从创意开始，按阶段带我完成到视频Prompt和后期方案。
```

### 改写已有剧本

```text
使用 $ai-native-video-architect-zh，
保留人物关系和结尾，诊断并改写下面的剧本，
然后拆成适合AI生图和图生视频的制作方案。
```

### 只做剧本后的制作

```text
使用 $ai-native-video-architect-zh，
剧本已经确定，不修改故事，
从剧本拆解、视觉圣经和资产计划开始，
输出完整资产Prompt、分镜帧Prompt和视频Prompt。
```

## 安装

```bash
git clone https://github.com/wlxb625/ai-native-video-architect.git
cd ai-native-video-architect/ai-native-video-architect-zh
```

复制到：

```text
Windows: %USERPROFILE%\.agents\skills\ai-native-video-architect-zh
macOS/Linux: $HOME/.agents/skills/ai-native-video-architect-zh
```

```bash
python scripts/validate_package.py
```
