# AI Native Film Studio V4.2

一套面向中文创作者的 **AI视频创作与导演级Prompt生产Skill**。

它既可以从一个想法开始完成故事和剧本，也可以在剧本确认后继续完成：

```text
最小核心参考图Prompt
→ 分镜设计
→ 分镜帧与控制帧Prompt
→ 导演级图生视频Prompt
→ 连续性、修复与后期
```

显式调用：

```text
$ai-native-video-architect-zh
```

## V4.2核心变化

### 剧本创作能力保留

继续支持故事、对白剧本、无对白视觉脚本、广告、MV、意识流、实验影像、诊断、改写和AI制作适配。

### 普通短片仍采用少量核心参考

默认每名主要角色一张综合角色板或三视图、每个主要场景一张空镜；核心道具和特殊状态按剧情需要增加。不会因为视频控制变详细而重新建立庞大资产库。

### 每镜先选择生成模式

支持：

- 单首帧；
- 首尾帧；
- 抽尾帧续拍；
- 两段硬切；
- 遮挡切换；
- 分层合成。

单首帧只用于低幅度运动且下一镜不依赖准确尾态。下一镜需要继承人物姿势、视线、手部、道具、焦点或构图时，必须预制尾帧或抽取稳定尾帧。

### 视频Prompt升级为导演级生成合同

每个镜头必须控制：

- 前景、中景、背景和构图；
- 分秒动作时间轴；
- 重量、接触、方向、距离和速度；
- 焦段、机位高度、距离、角度和轴线；
- 运镜开始时间、结束时间、幅度和终点；
- 焦点、景深、曝光、白平衡、高光和暗部；
- 真实主光、方向、高度、色温、软硬、光比、亮区和阴影；
- 可截图验证的精确结束帧；
- 下一镜继承、声音、稳定项和负面约束。

“人物缓慢移动，电影感，真实光照”不再被视为完整视频Prompt。

### 复杂镜头不强迫一次生成

镜面人物、倒影、雾气、精确文字、遮挡前后状态变化和复杂手部，优先使用控制帧、两段生成、遮挡硬切和分层合成。

## 可以从任何位置进入

### 从零创作

```text
使用 $ai-native-video-architect-zh，
帮我创作一部60秒无对白AI短片，
完成剧本后继续给我参考图、分镜帧和导演级视频Prompt。
```

### 使用已有剧本

```text
使用 $ai-native-video-architect-zh，
下面是已经确认的剧本，不修改故事和结尾，
直接完成参考图Prompt、分镜帧和视频Prompt。
```

### 只处理一个镜头

```text
使用 $ai-native-video-architect-zh，
为这个镜头选择合适的生成模式，
写首帧、尾帧、摄影、逐镜灯光、焦点和完整视频Prompt。
```

## 安装与验证

```bash
git clone https://github.com/wlxb625/ai-native-video-architect.git
cd ai-native-video-architect/ai-native-video-architect-zh
python scripts/validate_package.py
```

详细说明见 `ai-native-video-architect-zh/README.md`。
