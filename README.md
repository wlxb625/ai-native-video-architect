# AI Native Film Studio V4.2

一套面向中文创作者的 **AI视频创作与生产Skill**。

它可以从一个想法开始完成故事和剧本，也可以读取已有剧本、参考图、分镜或生成片段，继续完成生图Prompt、镜头设计、视频Prompt、生产组织、问题诊断和后期方案。

```text
$ai-native-video-architect-zh
```

## 主要功能

### 故事与剧本

- 从题材、人物、情绪或一个画面发展故事；
- 提供不同创意方向并比较优缺点；
- 完成一句话概念、故事方案、剧情剧本或无对白视觉脚本；
- 设计人物任务、关系、核心机制、递进、高潮、选择和结尾；
- 处理对白、旁白、环境声、动作声和画面文字；
- 支持高概念压缩、视觉叙事、意识流、广告、MV和实验影像；
- 诊断或改写已有作品，同时保护人物关系、关键选择、高潮和结尾。

### 生图与视觉设定

- 建立画幅、色彩、材质、摄影和灯光规则；
- 规划最少但够用的角色、场景、道具和特殊状态参考；
- 默认先使用单张角色身份主参考，不机械要求三视图或多宫格；
- 输出可直接复制的角色、场景、道具、首帧、尾帧和控制帧Prompt；
- 将构图、焦段、机位、焦点、曝光、灯光和材质融合进最终正向Prompt。

### 分镜与视频Prompt

- 一次性设计整片镜头表和摄影方案；
- 明确每镜的景别、焦段、机位、轴线、构图、动作、焦点、灯光、时长和结束状态；
- 根据镜头选择单首帧、首尾帧、尾帧续拍、两段硬切、遮挡切换或分层合成；
- 输出包含分秒动作、动作物理、摄影机、焦点、曝光、逐镜灯光、声音和精确尾帧的导演级视频Prompt；
- 对镜面、倒影、雾气、准确文字、复杂手部和状态变化进行拆段或分层处理。

### 实际生产与验收

- 从候选图中选定唯一角色、场景和道具母参考；
- 先测试普通代表镜头和必要的高风险镜头；
- 建立控制帧依赖、镜头生成顺序和版本台账；
- 检查换脸、服装漂移、场景重建、道具变形、手部错误、灯光漂移和尾帧失败；
- 判断问题来自参考图、控制帧、Prompt、模型能力还是后期；
- 规划重试、局部修复、硬切、续拍、分层合成、声音、调色和最终导出。

### 精品MV与视觉作品

V3积累的视觉叙事、视觉母题、声画关系、意识流和形式规则能力在V4.2中继续保留，并可以专门用于：

- 精品MV、视觉单曲和艺人概念片；
- 时尚影像、舞蹈与表演影像；
- 品牌情绪片、艺术短片和实验视觉作品；
- 从歌曲、歌词、节奏、艺人形象或一个核心视觉概念出发，设计音乐段落、视觉母题、表演、英雄镜头、声画同步、色彩灯光变化和结尾残像；
- 在完成视觉方案后继续进入参考图、分镜、视频Prompt、样片和实际生产。

## 可以从任何位置进入

- 只有一个模糊想法；
- 已有故事梗概或完整剧本；
- 已有角色图、场景图或道具图；
- 已有镜头表、分镜或首尾帧；
- 已有视频Prompt；
- 已有生成失败的图片或视频；
- 已进入剪辑阶段。

Skill会先识别用户已经完成的内容，只补当前缺失的部分，不强制从头开始。

## 使用示例

### 从零创作

```text
使用 $ai-native-video-architect-zh，
帮我创作一部60秒无对白悬疑短片，
完成剧本后继续制作参考图、分镜和视频Prompt。
```

### 制作精品MV

```text
使用 $ai-native-video-architect-zh，
根据这首歌、歌词和艺人视觉参考，
设计一支具有统一视觉母题和声画节奏的精品MV，
并继续完成参考图、分镜和视频Prompt。
```

### 使用已有剧本

```text
使用 $ai-native-video-architect-zh，
下面是已经确认的剧本，不修改人物关系、高潮和结尾，
直接进入视觉设定、参考图和分镜制作。
```

### 制作一个镜头

```text
使用 $ai-native-video-architect-zh，
根据这些角色图和场景图，
为当前镜头设计首帧、尾帧和完整视频Prompt。
```

### 检查生成结果

```text
使用 $ai-native-video-architect-zh，
检查这段视频的换脸、手部、灯光、尾帧和剪辑连接问题，
并给出最小修复方案。
```
