# AI Native Film Studio V4.1

一套面向中文创作者的 **AI视频创作与Prompt生产Skill**。

它既可以从一个想法开始完成故事和剧本，也可以在剧本确认后继续完成：

```text
角色与场景参考图Prompt
→ 分镜设计
→ 分镜帧Prompt
→ 图生视频Prompt
→ 连续性、修复与后期方案
```

不需要把剧本创作和后期Prompt生产拆成两个Skill。

显式调用：

```text
$ai-native-video-architect-zh
```

---

## 主要功能

### 1. 从想法完成故事与剧本

可以从一句灵感、一个角色、一种情绪或已有故事开始，完成：

- 创意方向与项目定位；
- 世界观、人物关系和核心机制；
- 故事结构、递进、高潮和结尾；
- 对白剧本；
- 无对白视觉脚本；
- 广告、MV、意识流或实验影像方案；
- 已有剧本诊断、改写和AI制作适配。

不会机械套用固定三幕结构，而是根据作品目标选择合适的叙事方式。

### 2. 从已有剧本直接开始制作

用户已经有完整剧本时，不要求重新做前期创作。

Skill会保护已确认的：

- 人物关系；
- 核心冲突或视觉规则；
- 关键选择；
- 高潮；
- 结尾；
- 用户明确要求保留的风格。

然后直接把剧本转译成AI生图、分镜和视频制作内容。

### 3. 统一视觉与生成规则

剧本确认后，可以建立：

- 画幅和整体摄影质感；
- 主色、辅助色和点缀色；
- 色温、饱和度和对比度；
- 真实光源、方向和暗部层次；
- 人物皮肤、服装、建筑和道具材质；
- 构图、景别和镜头语言；
- 禁止风格和必须保持项。

这些规则会自动继承到后续生图和视频Prompt中。

### 4. 输出核心参考图Prompt

普通短片默认使用少量高质量核心参考，不强制建立庞大的影视资产库。

通常包括：

- 每名主要角色一张综合角色板或三视图；
- 每个主要场景一张无人物空镜；
- 必须跨镜头稳定的核心道具结构板；
- 剧情强依赖的特殊状态板。

只有出现换脸、服装漂移、空间穿帮、道具变形或高风险交互失败时，才补充更细的面部、发型、服装、手部或多机位参考。

### 5. 依据专业资料编写生图Prompt

Skill内置了图片Prompt工程模块，可以根据角色、场景、道具和当前剧本编写可直接复制的Prompt。

当用户提供自己的教程、Prompt模板或制作资料时：

- 优先读取和使用原资料结构；
- 保留原资料中的主体提示和负面约束；
- 将当前项目内容填入模板；
- 自行补充的方法会与原资料明确区分。

图片Prompt重点控制：

```text
主体 + 场景 + 静态动作瞬间 + 服饰道具
+ 景别 + 机位 + 构图 + 光线色调
+ 材质真实度 + 风格 + 比例 + 负面约束
```

一张图片只负责一个准确瞬间，不让静态图片同时承担完整动作过程。

### 6. 设计完整分镜

可以把剧本一次性拆成完整镜头表，每个镜头包含：

- 镜头作用；
- 人物或环境的主要动作；
- 景别、机位和构图；
- 运镜及其叙事动机；
- 输入状态和输出状态；
- 时长、声音和剪辑连接；
- 需要引用的角色、场景和道具参考。

每个镜头只承担一个主要重点，避免无意义增加镜头和运镜。

### 7. 输出整片分镜帧Prompt

第一张分镜通常使用：

```text
角色参考 + 场景空镜 + 道具参考 + 当前镜头要求
```

后续分镜优先使用：

```text
角色参考 + 场景空镜 + 上一张满意分镜 + 当前镜头要求
```

这样可以在改变动作、景别和机位时，尽量保持人物身份、服装、场景和光线稳定。

不是所有镜头都强制使用首尾帧。只有动作终点、状态变化或模型需要时，才增加尾帧Prompt。

### 8. 输出图生视频Prompt

视频Prompt基于已选择的分镜图，重点控制：

- 唯一首帧；
- 人物起始状态；
- 一个主要动作；
- 动作方向、速度、幅度和收住；
- 一种主要运镜；
- 环境中的自然微动；
- 结束状态；
- 声音和禁止变化项。

基础结构：

```text
唯一首帧 + 起始状态 + 一个主要动作
+ 动作速度与幅度 + 一种主要运镜
+ 场景稳定要求 + 结束状态 + 声音 + 负面约束
```

固定镜头优先于无意义运镜，短镜头不会堆叠多个复杂动作。

### 9. 连续性、续拍与硬切

可以逐镜保持：

- 人物身份、年龄、发型和服装；
- 道具结构、位置、方向和状态；
- 场景布局和主光方向；
- 左右手、屏幕方向和动作进度；
- 上一镜结束状态与下一镜开始状态。

支持：

- 抽取上一段尾帧续拍；
- 换景别或机位时生成硬切新首帧；
- 多镜头动作进度衔接；
- 角色、场景和道具穿帮检查。

### 10. 失败修复与后期方案

遇到生成失败时，优先进行最小范围修复：

1. 简化Prompt或动作；
2. 局部重绘当前图片；
3. 改为固定机位；
4. 缩短视频片段；
5. 增加尾帧或硬切；
6. 最后才补充新的参考资产。

还可以输出：

- 剪辑与转场建议；
- 声音、环境音和音乐方案；
- 字幕和文字后期处理；
- 色调统一；
- 镜头版本命名；
- 成片审查与交付清单。

## 可以从任何位置进入

### 从零创作

```text
使用 $ai-native-video-architect-zh，
帮我创作一部60秒无对白AI短片，
完成剧本后继续给我角色场景Prompt、分镜和视频Prompt。
```

### 使用已有剧本

```text
使用 $ai-native-video-architect-zh，
下面是已经确认的剧本，不修改故事和结尾，
直接帮我完成参考图Prompt、分镜帧Prompt和视频Prompt。
```

### 使用已有图片

```text
使用 $ai-native-video-architect-zh，
这些是已经选好的角色图和场景图，
请据此设计完整分镜并输出每个镜头的视频Prompt。
```

### 只处理某个环节

```text
使用 $ai-native-video-architect-zh，
只帮我把这个镜头写成首帧、尾帧和图生视频Prompt，
不要修改剧本。
```

## 内部组织方式

Skill内部仍会区分故事、剧本、参考图、分镜帧、视频和修复模块，以保证前后内容一致。

这些模块是内部创作与生产依据，不是要求用户必须操作的网站式流程。用户已有成熟成果时，Skill会直接从对应位置继续。

## 安装

```bash
git clone https://github.com/wlxb625/ai-native-video-architect.git
cd ai-native-video-architect/ai-native-video-architect-zh
```

复制到：

```text
Windows: %USERPROFILE%\.agents\skills\ai-native-video-architect-zh
macOS/Linux: $HOME/.agents/skills/ai-native-video-architect-zh
```

验证安装：

```bash
python scripts/validate_package.py
```

更详细的模块说明见：

```text
ai-native-video-architect-zh/README.md
```

## 当前边界

Skill负责创作、导演设计和Prompt生产，不直接替代外部生图、视频生成、剪辑和声音软件。具体模型版本、价格、额度和平台规则不会永久写死，涉及当前工具能力时需要实时核实。
